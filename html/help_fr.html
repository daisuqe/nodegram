1. Qu’est-ce que nodegram ?

nodegram est un outil pour programmer avec des nœuds.

Reliez un nœud stick à un nœud personnage et le personnage se déplace déjà.



• Programmez sur téléphone comme sur ordinateur.

• Faites jouer vos jeux par d’autres personnes.
• nodegram vit sur le web : vous pouvez programmer partout où vous avez une connexion (un programme nodegram pèse à peine le poids d’une image).

Qu’est-ce que la programmation par nœuds (Node Programming) ?
nodegram propose plus de 40 sortes de nœuds : un nœud qui ne fait qu’additionner, un nœud qui retient un nombre, un nœud qui vérifie si une touche est enfoncée, etc.

La programmation par nœuds, ce sont des Nodes qui se passent des informations pour accomplir ensemble un gros travail. Chaque Node (un employé) prend les valeurs reçues des autres employés, fait son propre travail et transmet le résultat au suivant. Tous les Nodes (employés) travaillent en permanence, chacun de son côté.

La programmation textuelle classique fonctionne autrement : un seul employé lit les instructions une à une et les exécute dans l’ordre.

3. Prise en main

nodegram comporte trois vues :
Programmez vos nœuds dans NodeEditor
Placez vos objets dans Layout
Exécutez votre programme dans Play 

.

3-1. Créer des nœuds (NodeEditor)

  • Dans le NodeEditor, appuyez longuement sur le fond (la zone noire vide) pour ouvrir la boîte de dialogue « CREATE NEW NODE ».


  • Choisissez un nœud dans la liste et il apparaît dans le NodeEditor.
  • Appuyez longuement sur un nœud — ou double-cliquez dessus — pour ouvrir sa boîte de dialogue Property, où vous le configurez en détail.
    C’est là que vous changez par exemple la couleur d’un objet.
    Il n’y a pas de bouton OK : chaque modification prend effet immédiatement. Fermez la boîte avec le × en haut à droite, ou en touchant à côté.
    DUPLICATE copie le nœud et DELETE le supprime.
  • Faites glisser un nœud (touchez et déplacez) pour le repositionner.
  • Faites glisser depuis le port de sortie, à droite d’un nœud, jusqu’à un port d’entrée (à gauche d’un autre nœud) pour relier un fil. Pendant l’exécution, les valeurs circulent alors le long de ce fil, du port rouge vers le port bleu.



  • Les nœuds munis d’un port sur le dessus (port enfant) peuvent être reliés depuis ce port vers un port parent (sous un autre nœud). Les deux forment alors un couple parent-enfant, et l’enfant suit le parent lorsqu’il se déplace.
    Pour un joueur qui tire des projectiles, par exemple, faites du canon l’enfant et du joueur le parent.

3-2. Placer les objets (vue Layout)

  • Appuyez sur le bouton « Layout » pour passer à la vue Layout.


  • Dans Layout, vous disposez les nœuds objets comme Rect, Circle, Character et Text,
    ainsi que les nœuds de commande comme Button et Stick.


  • Faites glisser un objet pour le déplacer, utilisez les poignées blanches aux quatre coins pour le redimensionner, et la poignée ronde au-dessus pour l’orienter.
  • Appuyez sur « NODE » pour revenir au NodeEditor.

3-3. Exécuter le programme (vue Play)

  • Le bouton ▶ (Play) en haut à droite du NodeEditor ou de la vue Layout bascule vers Play et lance le programme.
  • Appuyez longuement sur le bouton □ (Stop) en haut à droite de la vue Play pour arrêter et revenir à l’édition.
  • Dans Play, les nœuds objets sont dessinés toutes les 1/60 de seconde (une image) et se déplacent avec la simulation physique.
  • On peut les commander en touchant l’écran, avec le joystick à l’écran, au clavier ou à la souris.


  • La vue Play permet aussi de représenter la gravité.
    Pour un jeu façon flipper ou Mario, activez Dynamics (la physique).
    Ajoutez un nœud Setting et activez Dynamics dans sa Property pour que la physique s’applique à tout le programme.
    Chaque nœud objet possède également son propre réglage Dynamics, à activer individuellement.

4. Les trois vues

4-1. Utiliser le NodeEditor

C’est l’écran où l’on dispose les nœuds et où on les relie par des fils.

C’est l’écran où l’on règle la position, la taille et la rotation des objets. Le rectangle gris représente la zone affichée pendant Play.


Les commandes sont pour l’essentiel les mêmes que dans le NodeEditor.

Lorsqu’elle est active, les objets se déplacent par pas de 10 pixels.

La taille de la zone grise se règle sur le nœud Setting.

5. MENU

Maintenez le bouton MENU en haut à droite, faites glisser le doigt vers un élément puis relâchez pour l’exécuter. Il fonctionne aussi comme un simple bouton.

Le bouton ▶ en haut à droite bascule vers Play et lance le programme.
Layout  bascule vers la vue Layout.

5-1. Les entrées du menu

NEW NODE Ouvre CREATE NODE pour ajouter un nœud. Un appui long sur le fond fait la même chose.
SAVE Enregistre le programme courant sous un nom (voir 5-2).
LOAD Charge un programme enregistré (voir 5-3).
UNDO Annule la dernière action.
REDO Rétablit une action annulée.
FIT Ajuste le zoom et la position pour que tous les nœuds tiennent à l’écran.
NEW Efface tout et démarre un nouveau programme.
SETTING Ouvre les réglages de l’application elle-même (voir 5-4). À ne pas confondre avec le nœud SETTING.
OPEN HELP Ouvre cette page d’aide.

Lorsque vous éditez l’intérieur d’un Compo, les entrées de gauche deviennent celles propres aux Compo. Elles sont décrites au chapitre « Les nœuds Compo ».

5-2. SAVE (enregistrer)

Enregistre le programme sur l’appareil sous le nom de votre choix. Un nom déjà utilisé est écrasé. Les noms acceptent les lettres et chiffres simples ainsi que quelques symboles.
AUTO pour activer l’enregistrement automatique : le programme est ensuite enregistré toutes les 30 secondes (jamais pendant Play).
EXPORT exporte le programme sous forme de fichier — pratique pour les sauvegardes et pour transmettre votre travail.
Deux formats au choix : .ngz (compressé en gzip) et .json (texte).
Il suffit de renommer un fichier .ngz en .gz pour qu’un logiciel de décompression ordinaire en extraie le JSON.

Vous pouvez conserver jusqu’à 256 enregistrements. Ils résident dans le navigateur utilisé et ne sont donc pas visibles depuis un autre appareil ou un autre navigateur.
Les données enregistrées se trouvent à l’intérieur de nodegram : supprimer le raccourci nodegram de votre téléphone risque donc de les supprimer aussi.
Pour tout ce qui compte, utilisez EXPORT et conservez un fichier.

5-3. LOAD (charger)

Affiche la liste des programmes enregistrés. Le bouton à côté de chaque nom permet aussi de supprimer.
IMPORT charge un fichier exporté auparavant. Deux modes : Charger remplace le contenu actuel, tandis que Ajouter conserve le programme en cours et place le fichier en dessous.

Importer un fichier .obj créé dans un logiciel 3D charge le modèle sous forme de nœud POLYGON, ou de nœud ARRAY relié à un nœud LINE (affichage 3D). Voir 11-12. Objets 3D pour le détail.

5-4. SETTING (réglages de l’application)

Réglages de l’application elle-même. Ils ne sont pas enregistrés dans le programme et restent sur cet appareil.
Wire : choisit la forme des fils (courbe ou droite).
NodeColor : choisit les couleurs des nœuds.
Language : change la langue de l’interface.
japonais, anglais, chinois (simplifié), français, allemand, hindi, indonésien, italien, coréen, portugais, russe, espagnol, thaï, turc et vietnamien

Les réglages propres à la scène (FPS, Dynamics, etc.) ne sont pas ici mais sur le nœud SETTING. Les noms se ressemblent : attention à ne pas les confondre.

6. Sur téléphone et sur ordinateur


Sur téléphone
  • Commandes tactiles :
    Déplacement à un doigt, zoom par pincement à deux doigts. L’appui long, le double-tap suivi d’un glissement, etc. fonctionnent comme sur ordinateur.

  • Rotation de l’écran :
    La vue suit l’orientation de l’appareil. Pendant Play, l’orientation définie sur le nœud SETTING (Horizontal ou Vertical) s’applique, et un message s’affiche si l’appareil est tenu dans l’autre sens.
  • Remarque pour iOS : 
    Sur iPhone et autres appareils iOS, ouvrez le menu de Safari et touchez ① puis ② pour masquer la barre d’outils : l’affichage devient quasiment plein écran et bien plus confortable.
    Pour un vrai plein écran, ouvrez le menu de partage de Safari et choisissez « Sur l’écran d’accueil ». nodegram se comporte alors comme une application : c’est ce que nous recommandons.
    Attention : supprimer cette icône de l’écran d’accueil peut effacer vos données enregistrées. Exportez ce qui compte vers un dossier de votre téléphone.

  • Raccourcis clavier :

7. Référence des nœuds



E/S indique le nombre de ports d’entrée / de sortie.

Constantes

Nœud Entrées/Sorties Description
Constant 0/1 Sort le nombre défini dans Value.

Calcul

Nœud E/S Description
＋ 2/1 Sort Entrée 1 + Entrée 2.
Un nœud d’addition n’est pas toujours nécessaire : tout port d’entrée accepte plusieurs fils et en fait la somme, si bien que deux fils sur l’Entrée 1 donnent déjà leur total.
－ 2/1 Sort Entrée 1 − Entrée 2
× 2/1 Sort Entrée 1 × Entrée 2
÷ 2/1 Sort Entrée 1 ÷ Entrée 2. Renvoie 0 si le diviseur est 0.
√ 1/1 Sort la racine carrée de l’Entrée 1. Renvoie 0 si l’entrée est inférieure ou égale à 0.
Compare 2/1 Compare l’Entrée 1 et l’Entrée 2 (=, >, <, ≠, ≥, ≤). Sort 1 si la comparaison est vraie, 0 sinon.
Not ( ! ) 1/1 Sort 1 quand l’Entrée 1 vaut 0, et 0 dans les autres cas.
Pos Angle 2/1 Position vers angle. Sort ArcTan2(Entrée 2, Entrée 1) en degrés.
Angle Pos 1/2 Angle vers position. Sort (cos, sin) pour un angle en degrés.
Random 1/1 Sort un entier aléatoire entre 0 et Number (exclu). Une nouvelle valeur est tirée au démarrage de Play et à chaque image où l’Entrée 1 est différente de 0. Activez Use Seed et fixez une valeur Seed pour retrouver la même suite à chaque lancement.
Int 1/1 Conversion en entier. La propriété Round propose Floor, Round et Integer.
Floor (par défaut) prend l’entier le plus proche inférieur ou égal à l’entrée : 2,8 devient 2 et −0,1 devient −1. Round arrondit au plus proche, Integer ne garde que la partie entière.

Valeurs et temporisation

Nœud E/S Description
Trigger 1/1 Sort 1 pendant une seule image, à l’instant où l’entrée passe de 0 à une valeur différente de 0.
DELAY(F) retarde ce 1 du nombre d’images indiqué.
Counter 2/1 Un compteur. Il ajoute l’Entrée 1 à chaque image, soustrait l’Entrée 2 et sort le nombre qu’il conserve.
Type = Clamp le maintient entre Min et Max ; Loop le fait boucler dans cet intervalle. Value (valeur initiale), Min et Max sont réglables.
Var 2/1 Sert de variable : il conserve un nombre et le sort.
Quand le signal de consigne sur l’Entrée 2 est différent de 0, il mémorise l’Entrée 1.
Une valeur initiale peut être définie.
Array 3/1 Sert de tableau.
Donnez un indice sur l’Entrée 2 (la position dans le tableau ; la première vaut 0) et il sort la valeur correspondante. Les indices commencent à 0 : un tableau de longueur 3 utilise 0, 1 ou 2 ; en dessous de 0 ou à partir de 3, il n’y a pas de valeur et 0 est renvoyé.
Un signal set sur l’Entrée 3 écrit la valeur de l’Entrée 1 dans l’élément d’indice Entrée 2.
Séparez les valeurs initiales par des virgules « , » ou des retours à la ligne.

Un Array peut être utilisé depuis plusieurs endroits à la fois : par exemple lire la 1re et la 3e valeur tout en écrivant la 2e dans la même image.
Pour cela, reliez plusieurs Array en parent et enfant. Seul l’Array le plus haut contient réellement les valeurs ; ceux du dessous ne sont que des interfaces d’accès vers lui. En cas d’écritures simultanées, le parent l’emporte. Seul l’Array le plus haut peut être relié à LINE / VOICE / SOUND.

Un tableau sert de partition avec les nœuds Sound et Voice, ou de polyligne avec le nœud Line. Un même Array peut être partagé par plusieurs Line. Les boutons SEQUENCER / LINE de la Property ouvrent l’éditeur de partition et l’éditeur graphique (chapitre 8).
Un tableau sert aussi à stocker un fil de fer 3D (voir 11-12. Objets 3D ).
GetPos 0/2 Lit la position X et Y courante de l’objet parent. Commutable entre WORLD et LOCAL.
GetRot 0/1 Sort l’angle courant de l’objet parent, le sens antihoraire étant positif. Commutable entre WORLD et LOCAL.
Velocity 0/2 Sort la vitesse X et Y de l’objet parent, par seconde (Y positif vers le haut). Une valeur Frames plus grande moyenne sur davantage d’images et lisse la lecture.

Le contenu d’un Array se modifie dans des éditeurs dédiés : le bouton SEQUENCER de la Property l’édite comme une partition, le bouton LINE comme une polyligne. Pour leur utilisation, voir 8. Les éditeurs .


Sorties et objets

Nœud E/S Description
Text 2/0 Affiche du texte. Sans fil connecté, il montre le texte de la propriété Text ; avec un fil, il montre la valeur. L’Entrée 2 active ou désactive l’affichage. Les nombres sont arrondis à la sixième décimale et affichés jusqu’à la cinquième. Couleur du texte, mise en page et cadre sont réglables.
Rect 3/0 Un rectangle. Avec Dynamics désactivé, les Entrées 1 et 2 sont les coordonnées x et y ; avec Dynamics activé, une force extérieure x,y. L’Entrée 3 affiche ou masque l’objet. Couleur, bordure, Tag, taille, rotation, Sorting Layer, etc. sont réglables. Broken by 1–3 indique le My Tag des objets capables de détruire celui-ci.
Pour Dynamics et Tag, voir 11. Spécifications .
Circle 3/0 Un cercle. Hormis sa forme et la propriété Radius, ses entrées et propriétés sont celles de RECT.
Character 3/0 Un personnage qui peut marcher et sauter. Les Entrées 1 et 2 sont la vitesse de déplacement ; l’Entrée 3 saute à l’instant où elle passe d’une valeur ≤ 0 à une valeur positive.
La force du saut est proportionnelle à la valeur d’entrée et ne fonctionne qu’au sol. Pour la physique et le saut, activez Dynamics à la fois dans SETTING et dans le Character. Pour une vue de dessus, laissez Dynamics activé et mettez Gravity à 0. Flip retourne la texture selon la direction, AutoRot oriente le personnage dans le sens de la marche et KeepOnScr le garde dans l’écran.
Il a un port enfant, mais ne peut pas devenir l’enfant d’un objet. Le seul parent possible est WARP IN.
Shot 1/1 L’Entrée 1 tire un projectile. Bullet Count est le nombre de projectiles pouvant exister simultanément. My Tag détruit tout ce dont le Broken by correspond, tandis que le Broken by 1–3 du nœud SHOT indique ce qui fait disparaître ses projectiles, par type de nœud ou par Tag. La sortie vaut 1 uniquement sur les images où un tir a réellement eu lieu. Keep Off-Screen conserve les projectiles hors écran, et lorsque la limite est atteinte les plus anciens disparaissent.
Line 5/0 Trace une ligne de (X1,Y1) à (X2,Y2). Si l’Entrée 5 (SET) est reliée, la forme se met à jour quand elle reçoit une valeur non nulle et garde la forme précédente tant qu’elle vaut 0 ; sinon, elle se met à jour à chaque image.
Avec un ARRAY enfant, les Entrées 1 à 4 sont ignorées : le tableau est lu comme x1,y1,x2,y2,… et tracé en une seule polyligne continue. x=9999, y=9999 coupe la ligne. Coord choisit WORLD ou LOCAL.
Si l’ARRAY enfant contient des données 3D (triplets x,y,z), il est automatiquement tracé en 3D LINE. Pour le détail, voir chapitre 8, l’éditeur LINE.
Sound 4/2 L’Entrée 1 est le signal de lecture, l’Entrée 2 la hauteur (do=0, ré=1…) et l’Entrée 3 le volume. Si les Entrées 2/3 ne sont pas reliées, les propriétés Tone/Volume sont utilisées. Un son tenu joue tant que Signal (Entrée 1) n’est pas nul ; les sons qui s’éteignent et les effets jouent une fois au front montant de Signal ou quand la hauteur change. La hauteur 99 est un silence. La propriété Tone avance par pas de 0,5 (un demi-ton), mais l’Entrée 2 accepte des décimales continues.
Avec Chromatic activé, Tone devient un numéro de demi-ton sur 12 notes (0=do, 1=do#, 2=ré…). Désactivé, la gamme a 7 degrés et 0,5 est une touche noire. Si un Array fournit la hauteur, réglez Chromatic comme dans le SEQUENCER de cet Array, sinon les notes seront décalées.
L’Entrée 4 Pan règle la balance stéréo gauche/droite entre −1 et +1.

Reliez un Array directement comme enfant et ce Sound joue la partition tout seul. Les propriétés Tempo (BPM) et Loop apparaissent, et l’Entrée 2 devient un décalage de transposition (1 = un demi-ton) au lieu de la hauteur. La Sortie 1 est un signal qui vaut 1 pendant une image à la fin de la lecture, et la Sortie 2 le temps écoulé en secondes depuis le début ; elles servent à synchroniser d’autres nœuds sur la musique. L’Entrée 1 lance la lecture ; à 0 elle s’arrête, et redevenue non nulle elle reprend depuis le début.
La valeur 90 dans l’Array est une liaison qui signifie « prolonger la note précédente » : c’est ainsi qu’on distingue une même hauteur rejouée d’une note tenue.
Appuyez sur le bouton « Sequencer » de l’Array relié au Sound pour modifier la partition. Pour le détail, voir chapitre 8, Sequencer.
Voice 3/2 Un nœud qui fait prononcer des kana japonais. Écrivez des hiragana (les katakana fonctionnent aussi) dans la propriété Line : la voix est synthétisée sur le moment (synthèse par formants).
L’Entrée 1 est le signal de lecture : son front montant lance la lecture depuis le début, et un retour à 0 l’arrête même en cours. L’Entrée 2 est le volume.
La Sortie 1 est un signal qui vaut 1 pendant une image à la fin de la lecture, et la Sortie 2 le temps écoulé en secondes depuis le début. En la divisant par la durée d’une colonne, vous savez quelle note est en cours, pratique pour caler un accompagnement ou des sous-titres sur le chant. Le numéro de note vaut « Time × BPM ÷ 30 ».
Les voix sont Girl / Boy / Woman / Man / Child / Plain / Robot, et Pitch décale la voix par demi-tons.
L’Entrée 3 Pan règle la balance stéréo gauche/droite entre −1 et +1.

Reliez un Array comme enfant et le nœud chante. Les kana sont attribués aux notes un par un, et Tempo (BPM) règle la vitesse. Sans Array, c’est Speed (millisecondes par kana) qui règle le débit à la place de Tempo.
La règle est un kana par note. Les liaisons (90) et les silences (99) n’utilisent pas de kana. En chant, « 、 » et « 。 » sont ignorés. Le trait d’allongement « ー » occupe une note à lui seul et peut passer à une autre hauteur en gardant la voyelle précédente (un legato).
Une note sans kana disponible devient un « · » rouge et reste muette.
Les paroles se modifient dans les propriétés de Voice et les hauteurs dans le SEQUENCER de l’Array ; les boutons → ARRAY ／ → VOICE font passer de l’un à l’autre.
Pour le détail, voir chapitre 8 , Sequencer.
Polygon 7/0 Un objet qui affiche les faces (polygones) d’un modèle 3D. Il ne se crée pas depuis CREATE NEW NODE : il n’apparaît qu’à l’IMPORT d’un fichier .obj.
Ses entrées sont une position 3D, une rotation 3D et une échelle.
Pour le détail, voir 11-12. Objets 3D .

Commandes

Nœud E/S Description
Stick 1/2 Un joystick à l’écran. La Sortie 1 donne l’inclinaison horizontale du stick et la Sortie 2 son inclinaison verticale. Analogique ou numérique, avec affectation possible au clavier ou à une manette.
Button 1/1 Bouton virtuel. Vaut 1 tant qu’il est enfoncé. Il peut être affecté au clavier ou à une manette.
Un nœud Button est fixé à l’écran, mais si vous lui donnez un parent, il est fixé à cet objet.
Keyboard 0/1 Sort 1 tant que la touche choisie est enfoncée.
Touch 0/3 Toucher l’écran. La Sortie 1 donne le X du contact et la Sortie 2 son Y (le centre vaut 0,0) ; la Sortie 3 vaut 1 tant que l’écran est touché.

  Autres nœuds

Nœud E/S Description
TEXTURE 1/0 Contient un dessin en pixels que vous réalisez et l’applique sur l’objet défini comme parent. Affectable à Rect, Circle, Chara, Shot et BG, et peut avoir plusieurs parents (plusieurs nœuds objets).
Une entrée à 0 le masque. Reliez plusieurs textures à un même objet et n’en rendez qu’une Visible pour passer de l’une à l’autre.
On choisit si l’image est ajustée à l’objet ou répétée en mosaïque.
Sans parent, la texture peut aussi s’afficher seule, comme une image plane.
Lorsque la même image sert de nombreuses fois — pour des tuiles de décor, par exemple — une seule texture peut être affectée à plusieurs objets.
Pour l’éditeur de texture lui-même, voir « l’éditeur TEXTURE ».
SENSOR 0/1 Sort le nombre d’objets qui chevauchent la zone du capteur (la région définie dans la vue Layout). Un objet compte s’il satisfait la condition Target ou l’un des Tags 1 à 3, et chaque objet n’est compté qu’une fois même s’il en satisfait plusieurs. Target=SCREEN renvoie plutôt 0 ou 1 selon que la zone du capteur chevauche ou non l’affichage courant. Avec un parent, le capteur suit ce parent, lequel est exclu de la détection.
ONBREAK 1/1 Sort le nombre d’objets parents, ou d’objets portant le Tag choisi, détruits pendant l’image en cours. Plusieurs objets parents peuvent être définis.
Sans rien à surveiller, un nœud Onbreak sert de nœud d’effet : quand l’Entrée 1 passe de 0 à une autre valeur, il joue aussi un effet à sa position et ajoute 1 à sa sortie pour cette image (sans parent ni Tag, vous pouvez par exemple faire briller un effet depuis une entrée tout en jouant un son). Le type d’effet (NONE, PARTICLE, LINE, CIRCLE, BOX) et sa couleur sont réglables.
ROTATE 1/0 Une charnière servant à faire pivoter un ensemble parent-enfant. Un objet ayant ROTATE pour parent en reprend la position et la rotation. L’Entrée 1 est le décalage de rotation par rapport à l’angle défini dans Layout, les valeurs positives tournant dans le sens antihoraire.
SCREEN 3/2 Commande la caméra pendant Play. X/Y donnent la position de la caméra (un décalage par rapport au parent s’il y en a un ; Y positif vers le haut) et S le zoom, avec un minimum de 0,05. Un objet ayant SCREEN pour parent devient un HUD fixe, insensible à la caméra.
Désignez l’objet du joueur comme parent de SCREEN et la vue suit le joueur.
RESTART 1/1 Quand l’entrée passe de 0 à une valeur différente de 0, tout le programme revient à l’état qu’il avait au démarrage de Play. Positions, variables, compteurs, tableaux, projectiles, etc. sont réinitialisés. La valeur qui a déclenché le redémarrage reste présente en sortie, ce qui est commode pour reporter le nombre de vies ou le score.
COMPO 3/3 Un composant qui regroupe plusieurs nœuds en un seul. E active ou désactive ; 1 et 2 échangent des valeurs avec l’intérieur.
Pour le détail, voir 9. Les nœuds Compo .
  • L’éditeur TEXTURE：
    Ouvrez-le depuis le bouton « Edit Texture » de la Property d’un nœud TEXTURE. Pour son utilisation, voir 8. Les éditeurs .

    • Téléportation

    Nœud E/S Description
    WARP IN 1/0 L’« entrée » d’un mécanisme qui téléporte un objet ailleurs. Il agit sur l’objet défini comme enfant. Quand l’entrée reçoit une valeur non nulle, cet objet saute à la position et à l’angle du WARP OUT de même Index. Tant que la valeur reste non nulle, il y reste bloqué ; quand elle revient à 0, il est libéré et bouge de nouveau librement. Index est sa seule propriété. Impossible à placer dans un Compo.
    Le bouton Next IN passe à la Property du WARP IN suivant de même indice, et To OUT à celle du WARP OUT de même indice.
    WARP OUT 0/0 La « sortie » d’une téléportation. Les objets envoyés par un WARP IN de même Index arrivent à cette position et à cet angle. Index est sa seule propriété. Dans la vue Layout, on peut le déplacer et le faire pivoter (il n’a pas de taille, donc pas de redimensionnement). Donnez-lui un objet parent et il se déplace avec lui. Impossible à placer dans un Compo.
    Le bouton To IN passe à la Property du WARP IN de même indice.

    Signaux

    Nœud E/S Description
    IN 1/0 Sert à envoyer la sortie d’un nœud loin sans tirer de long fil. Le signal relié à un nœud IN ressort des nœuds OUT de même indice. On ne peut pas créer deux nœuds IN de même indice. Avec l’indice d’un nœud Compo, il permet aussi d’accéder à l’intérieur du Compo.

    Vous pouvez aussi donner un nom à l’indice ; il s’affiche à la place du numéro.
    Pour les nœuds Compo, voir 9. Les nœuds Compo .
    OUT 0/1 Sert à amener un signal de loin vers l’entrée d’un nœud. Le signal relié à un nœud IN ressort des nœuds OUT de même indice. On peut créer plusieurs nœuds OUT de même indice : la valeur entrée dans l’IN ressort de tous. Avec l’indice d’un nœud Compo, il permet aussi d’accéder à l’intérieur du Compo.
    Le bouton Next OUT passe à la Property du nœud OUT suivant de même indice, et To IN à celle du nœud IN de même indice.
    Vous pouvez aussi donner un nom à l’indice ; il s’affiche à la place du numéro.

    Nœud E/S Description
    MEMO 0/0 Une note que vous écrivez sur le plan de travail. Elle n’est pas affichée pendant Play.
    BG 0/0 Le fond de la vue Play. Un seul par scène, toujours à l’arrière-plan.

8. Les éditeurs

Des écrans d’édition dédiés, ouverts depuis la Property d’un nœud. LINE et SEQUENCER créent le contenu d’un nœud Array, TEXTURE celui d’un nœud Texture. Chaque éditeur se ferme avec le × en haut à droite, et son contenu est écrit dans le nœud à la fermeture. ◁ / ▷ annulent et rétablissent dans chaque éditeur.

8-1. L’éditeur LINE

Un outil pour dessiner la polyligne à relier à un nœud Line. Ouvrez-le depuis le bouton LINE de la Property d’un nœud Array.
L’origine est au centre de la zone d’édition ; X est positif vers la droite et Y vers le haut, de -99 à 99.
DRAW trace la polyligne. Pendant le tracé, le bouton DRAW devient Endpoint ; appuyez dessus pour terminer le trait.
MOVE déplace un sommet, ERASE supprime un seul segment, VIEW déplace la vue.
À la fermeture, le dessin devient une suite de nombres x,y, où x,y = (9999,9999) coupe la ligne.

Définissez un nœud Line comme parent d’un nœud Array et ce Line dessine le contenu de l’Array. Un même Array peut avoir plusieurs nœuds Line comme parents.

8-2. L’éditeur SEQUENCER

Un outil pour créer la partition (un Array) jouée par les nœuds Sound ou Voice. Ouvrez-le depuis le bouton SEQUENCER de la Property d’un nœud Array.
1 colonne = une croche, 1 mesure = 8 colonnes, jusqu’à 500 mesures, 6 octaves (3 sous le do central et 3 au-dessus). Trois octaves sont visibles à la fois ; faites défiler verticalement pour voir le reste.

・Modes

DRAWTouchez ou faites glisser sur un espace vide pour placer des notes. Touchez une note pour changer sa hauteur, faites-la glisser pour la déplacer.
ERASEFaites glisser pour effacer en continu. Toucher une note n’importe où efface la note entière.
RESIZEChange uniquement la longueur d’une note. Faites glisser une note : son extrémité droite s’allonge ou raccourcit du nombre de colonnes parcourues.
Copy / PasteCopie une plage de colonnes et la colle. Déplacer la position de collage vers le haut ou le bas transpose.
VIEWDéplace la vue. Pincez ou utilisez la molette pour zoomer ; le glisser au bouton du milieu déplace aussi verticalement.

・ Durée des notes, liaisons et legato

Une note écrite « valeur de hauteur, 90, 90, 90 » dure 4 colonnes. 90 est une liaison qui signifie « prolonger la note précédente » ; elle s’écrit automatiquement quand vous allongez une note avec RESIZE.

Autrement dit, jouer deux fois la même hauteur et tenir une seule note ne diffèrent que par la seconde valeur : une hauteur ou 90.

0,0Deux croches do : do, do
0,90Une noire do
99Silence
Pour Voice en revanche, deux croches chantées « ド » puis le trait d’allongement « ー » sonnent comme une seule noire do.
Comme « ド » et « ー » sont deux notes distinctes, vous pouvez aussi leur donner des hauteurs différentes : on obtient alors un legato (passer d’une hauteur à l’autre sans coupure).

・ Valeurs de hauteur

Do vaut 0, ré 1 et do# 0,5.
La mesure qui contient la dernière note est complétée par des silences (99 dans le tableau) jusqu’à sa fin.
Avec CHROMATIC activé, chaque case devient un demi-ton (do=0, do♯=1, ré=2, ré♯=3, mi=4, fa=5, fa♯=6, sol=7, sol♯=8, la=9, la♯=10, si=11) et une octave vaut 12. Basculer CHROMATIC convertit aussi les nombres de l’Array et le réglage Chromatic des nœuds Sound reliés.
Avec MAJOR activé, seules les touches blanches peuvent être posées (les notes noires déjà présentes sont conservées).

・Nœuds Sound / Voice 

Si l’Array est l’enfant d’un Sound ou d’un Voice, BPM et Source (l’instrument) sont une seule valeur partagée par tous ceux qui utilisent cet Array. Vous pouvez les changer depuis le séquenceur ou depuis la Property du nœud parent ; dans les deux cas, tout prend la même valeur. CHROMATIC n’appartient au Sound que lorsqu’un Sound est le parent, et ne se change pas dans le séquenceur. Les boutons → SOUND ／ → VOICE en bas à gauche mènent à ce nœud parent.
Pour un Array sans parent, BPM et instrument sont des réglages propres à cet Array.

・ Écoute

Le bouton de lecture joue la partition. Pendant la lecture, touchez une colonne pour y déplacer la position de lecture.
Un Sequencer relié à un nœud Voice affiche les kana des paroles au-dessus des notes.

Un Array seul ne produit aucun son dans le jeu. Associez-le à Sound ou Voice.

・ Éditer plusieurs séquences ensemble

Sélectionnez plusieurs nœuds Array dans le NodeEditor, maintenez l’un d’eux appuyé et choisissez « SEQUENCER » : jusqu’à 7 d’entre eux s’éditent sur la même grille.
Touchez un bouton numéroté pour changer celui que vous éditez, maintenez-le pour le volume et la sourdine, faites-le glisser pour changer l’ordre. La couleur et l’instrument se règlent pour chaque Array.

8-3. L’éditeur TEXTURE

Ouvrez-le depuis le bouton « Edit Texture » de la Property d’un nœud Texture. Dessinez en pixels : le dessin est appliqué sur l’objet défini comme parent.

DrawDessine des points dans la couleur choisie. Glissez pour dessiner en continu.
PaintRemplit une zone contiguë de même couleur.
PickPrélève une couleur du dessin et en fait la couleur courante.
ViewZoome et déplace la vue.
Copy / PasteCopie une zone sélectionnée et la colle ailleurs.
◁ / ▷UNDO / REDO

Choisissez une couleur dans la palette du bas. Pour effacer, prenez la couleur transparente et dessinez avec. Maintenez une case de la palette pour choisir n’importe quelle couleur.
Le nombre de pixels se règle avec la propriété Size. On peut aller jusqu’à 256×256, mais le nombre d’annulations diminue et l’éditeur ralentit. Pour les objets SHOT, utilisez des textures aussi petites que possible.
Sur ordinateur, vous pouvez coller dans l’éditeur une image copiée depuis un autre logiciel. Selon l’application et l’appareil, cela peut aussi marcher sur téléphone.

9. Les nœuds Compo

  • Un nœud particulier, qui permet de manipuler tout un groupe de nœuds comme s’il n’y en avait qu’un.

    Imaginez que la même combinaison de nœuds revienne dix fois dans votre programme : vous voudriez la construire une seule fois et la réutiliser.
    nodegram permet justement de regrouper plusieurs nœuds en un nœud Compo, puis de dupliquer ce Compo.

    Pour obtenir dix fois le même ennemi, construisez-en un, regroupez ses nœuds dans un Compo, dupliquez le Compo et placez les copies dans Layout.

    Les Compo dupliqués partagent un seul et même programme : modifier l’un modifie donc les autres — mais chaque copie conserve ses propres coordonnées, variables, durée de vie, etc. pendant l’exécution.

  • Créer un nœud Compo
  1. Sélectionnez ensemble les nœuds à regrouper.
    Pour en sélectionner plusieurs, double-cliquez puis glissez.
    Au deuxième clic, gardez le bouton enfoncé et tirez un rectangle de sélection.
    Sur téléphone, cela ressemble à « tap, tap-maintenu, balayage ».
    (Dans cet exemple, le joueur est à gauche et la zone encadrée est le programme d’un ennemi qui s’approche de lui.)



  2. Plusieurs nœuds étant sélectionnés, appuyez longuement sur l’un d’eux pour ouvrir le menu. Choisissez « MAKE COMPO » et confirmez par « Yes ».




  3. Les nœuds sont devenus un unique nœud Compo nommé « C1 ».


  4. Appuyez longuement sur C1 (ou double-cliquez) pour entrer dedans et l’éditer dans son propre NodeEditor.
    Les fils qui arrivaient au Compo apparaissent maintenant comme des nœuds OUT nommés « C1 1 » et « C1 2 ».

    Appuyez sur « MENU » à droite : la colonne de gauche contient désormais les commandes propres aux Compo.
    « Duplicate » crée une copie de ce nœud Compo.
    Le bouton « PARENT » en bas à droite quitte ce NodeEditor et revient à celui du dessus.



  5. De retour dans le NodeEditor parent, on voit qu’il existe maintenant plusieurs nœuds Compo.
    Nous voulons que « C1 (2) » reçoive la même entrée : reliez-le de la même façon.



  6. Appuyez sur « LAYOUT » et placez chaque Compo où vous le souhaitez.


  7. Appuyez sur Play « ▶ » : plusieurs ennemis apparaissent, chacun se déplaçant de son côté.

  8. Pour faire beaucoup de copies d’un coup, sélectionnez les nœuds Compo ensemble, appuyez longuement sur l’un d’eux et choisissez « Duplicate ».
    Lorsque tous les Compo doivent recevoir la même valeur, les nœuds IN et OUT sont le moyen commode de la leur transmettre.


  • Nœuds Compo et instances

    Quand deux nœuds Compo contiennent le même programme, si bien que modifier l’un modifie l’autre, on dit que les deux nœuds sont instances l’un de l’autre ; dupliquer un Compo, c’est « en créer une instance ».
    Les nœuds Compo portant le même numéro de Compo sont instances l’un de l’autre et partagent un seul programme.
    (Rompre ce lien s’appelle Unique, dans le menu à balayage du Compo. Voir plus bas)

    Le numéro qui suit le C indique de quel Compo il s’agit : même numéro, mêmes instances d’un même Compo.
    « C1 (1) » et « C1 (2) » sont instances l’un de l’autre.
    « C1 (1) » et « C2 (1) » sont deux Compo différents, sans lien entre eux.
    Le nombre entre parenthèses ne sert qu’à distinguer les copies d’un même Compo.

    Même lorsque des Compo sont instances l’un de l’autre, chaque paramètre est traité séparément pendant Play.
    Apparition et destruction, coordonnées, ainsi que les nœuds count, var et array situés à l’intérieur, conservent chacun leurs propres valeurs.

  • Le MENU à l’intérieur d’un nœud Compo


    Duplicate et Delete : dupliquer ou supprimer le nœud Compo.

    Unique     : rompt le lien de ce Compo avec ses instances. À utiliser pour reprendre le contenu d’un Compo et en faire un autre ennemi. La copie reçoit un nouveau numéro de Compo.

    Expand     : ressort les nœuds du Compo en cours d’édition dans le NodeEditor principal ; le Compo lui-même disparaît. C’est l’inverse de Make Compo. Les Compo qui en sont des instances ne sont pas développés avec lui.

  • Les nœuds Compo avec IN et OUT

    Un nœud Compo n’a que deux ports d’entrée et deux de sortie, mais les nœuds IN et OUT permettent d’en ajouter.
    Les nœuds IN et OUT possèdent un numéro de Compo dans leurs propriétés : on peut donc transmettre une valeur à un Compo précis.


    À l’intérieur d’un Compo, vous pouvez utiliser un nœud OUT sans numéro de Compo.
    À l’intérieur d’un Compo, un nœud IN sans numéro de Compo est impossible, car deux nœuds IN identiques ne sont pas autorisés.

    Attention : un nœud IN ou OUT portant un numéro de Compo signifie tout autre chose selon qu’il se trouve à l’intérieur ou à l’extérieur du Compo.
    Sur l’image ci-dessus, le « nœud IN (bleu) : C1, index 2 » apparaît à la fois dans le Compo et en dehors, et les deux ne sont pas la même chose. Celui de l’intérieur est relié à la sortie 2 du Compo, tandis que celui de l’extérieur est relié à l’entrée 2 du Compo et transmet sa valeur au « nœud OUT : C1, index 2 » situé à l’intérieur.

  • Les entrées et sorties Enable d’un Compo

    Lorsque vous utilisez un nœud Compo comme personnage, les entrées et sorties Enable commandent son apparition et sa disparition.

    La sortie Enable vaut 1 tant que le personnage existe et passe à 0 dès qu’il est détruit.

    Quand l’entrée Enable passe de 0 à 1 (ou à toute valeur non nulle), le programme du Compo démarre et le personnage devient actif. Il ne reste en vie que tant que cette entrée reste non nulle : si elle revient à 0, ou si le personnage est détruit, il disparaît.
    Si rien n’est relié à l’entrée Enable, tout se passe comme si 1 y était relié en permanence.

    Même un personnage disparu repart de son état initial dès que l’entrée repasse de 0 à une valeur non nulle.
    Voici un programme qui fait réapparaître le personnage à sa position de départ trois secondes après sa destruction.


  • Un seul parent par nœud Compo

    À l’intérieur d’un Compo, la chaîne parent-enfant des objets ne doit pas comporter plus d’un objet parent de premier niveau. Créer deux personnages dans un même nœud Compo n’est pas prévu.
    Deux parents ne posent pas de problème dès lors qu’ils partagent un parent commun au-dessus d’eux.
    N’avoir aucun nœud objet (et donc aucun parent) ne pose pas de problème non plus.


  • Nœuds impossibles à créer dans un Compo

    BG, Setting, Stick, Button, Screen et OnBreak ne peuvent pas être créés dans un Compo.

11. Spécifications

11-1. 2D uniquement

nodegram est uniquement 2D. Il y a deux axes : X (positif vers la droite) et Y (positif vers le haut). Activez Dynamics dans le nœud Setting et les personnages tombent vers le bas de l’écran.
Pour un jeu vu de dessus, désactivez Dynamics dans le nœud SETTING ou mettez la gravité globale à 0.
Les polygones et les fils de fer 3D sont utilisables, mais ils sont traités comme des objets 2D capables d’un affichage 3D.

11-2. FPS

Choisissez une fréquence d’images cible de 60 ou 30 sur le nœud SETTING (60 par défaut). L’évaluation des nœuds comme la physique avancent à ce rythme. Si le programme devient trop lourd, Play ralentit et la fréquence réelle descend sous la valeur choisie.

11-3. Dynamics (physique)

Les objets tels que Rect, Circle, Character et Shot peuvent recevoir un mode physique (Dynamics). Le comportement est proche du Rigidbody2D d’Unity.

Mode Comportement
Off Aucune physique. Les entrées du nœud (X,Y) déplacent simplement l’objet.
Static Un mur ou un sol immobile. Ni la gravité ni les collisions ne le déplacent.
Dynamic Se déplace physiquement sous l’effet de la gravité et des collisions. Les entrées X/Y du nœud s’appliquent comme une force.
Kinematic La gravité et les collisions ne le déplacent pas, mais les entrées du nœud si ; il entre malgré tout en collision avec les objets Dynamic et les pousse.

Il n’y a pas de réglage de densité : tout est traité comme du bois, en gros.

11-4. SortingLayer (ordre d’affichage)

Le SortingLayer de chaque objet (0–100, 50 par défaut) détermine l’ordre de superposition dans la vue Play. Plus le nombre est grand, plus l’objet est au premier plan. BG (le fond) reste toujours tout à l’arrière.
À valeur égale, les objets s’affichent dans leur ordre d’ajout.

11-5. Coordonnées

  • X est positif vers la droite et Y positif vers le haut. Le centre de la vue Layout est l’origine (0,0).
  • Les angles sont en degrés et le sens antihoraire est positif. 0° correspond à la droite (X+), 90° au haut (Y+), 180° à la gauche (X−) et 270° au bas (Y−). ANGLE POS, POS ANGLE, GetRot, ROTATE et la propriété Angle des objets suivent tous cette convention.
  • La propriété Coord d’un objet change le sens des entrées X/Y des nœuds.
    • WORLD : l’entrée est une position absolue (relative au parent si l’objet en a un).
    • LOCAL : l’entrée est un décalage par rapport à la position de départ de l’objet. Avec un parent, le décalage par rapport au parent est également compris (coordonnées du parent).
  • Pour les coordonnées des objets 3D, voir 11-12. Objets 3D.

11-6. Résolution

La zone affichée pendant Play correspond au rectangle gris de la vue Layout.
L’orientation (Horizontal ou Vertical) se règle sur le nœud SETTING — et non dans le menu Setting — et l’affichage s’adapte à la taille réelle de l’écran.
Pour une résolution fixe, utilisez ScreenSize sur le nœud Setting.

11-7. Tag

Un Tag est un groupe.
Vous pouvez par exemple donner le Tag « Enemy_tiny » à tous les petits ennemis, ou distinguer le décor destructible du reste avec « bg_destroyed » et « bg ».
Les nœuds Shot, OnBreak, Rect, Circle et Character utilisent tous les Tags.


11-8. Les nœuds


  • Un port d’entrée accepte plusieurs fils à la fois, et le nœud en reçoit la somme. Sur l’image, le port du haut reçoit 10+20 = 30.

  • Une liaison parent-enfant entre nœuds (du port du dessus vers un port du dessous) ne sert pas qu’à déplacer les objets ensemble : elle exprime aussi une relation.
    C’est ainsi qu’un nœud Texture est lié à un nœud objet, un nœud OnBreak à l’objet qu’il surveille, et un nœud Array à un nœud Line.
    Normalement un parent peut avoir plusieurs enfants, mais un enfant n’a qu’un seul parent.
    Les nœuds Texture, OnBreak et Array font exception : chacun peut avoir plusieurs parents.


11-9. Le menu multi-nœuds


Double-cliquez et faites glisser au second clic pour sélectionner plusieurs nœuds d’un rectangle. Avec plusieurs nœuds sélectionnés, vous pouvez faire ce qui suit.

PROPERTYApparaît quand tous les nœuds sélectionnés sont du même type. Pratique pour changer la Property de tous à la fois.
MAKE COMPOTransforme les nœuds en un Compo. Voir 9. Les nœuds Compo.
DUPLICATEDuplique tous les nœuds sélectionnés.
DELETESupprime tous les nœuds sélectionnés.

11-10. Ce qui se passe en une image

Tous les nœuds sont traités en même temps.
L’ordre dans lequel vous les avez créés ne change jamais le résultat.

Les nœuds objets et assimilés sont traités une fois par image.
Les nœuds qui retiennent une valeur — Counter, Var, Trigger, Random, Array — ne sont eux aussi mis à jour qu’une fois par image.
Les nœuds de calcul comme + et × ne retiennent rien : ils sont évalués au moment où leur valeur est nécessaire.
Malgré tout, si des nœuds de calcul forment une boucle, chaque nœud n’est traité qu’une seule fois par image.

11-11. UNDO / REDO

Les commandes UNDO / REDO du MENU annulent et rétablissent création, suppression, déplacement, câblage, changement de propriété, etc. Vous pouvez revenir jusqu’à 50 étapes en arrière.

Les éditeurs TEXTURE, LINE et SEQUENCER possèdent chacun leur propre historique ; utilisez les boutons ◁ / ▷ à l’intérieur de l’éditeur. L’éditeur LINE et le SEQUENCER remontent eux aussi 50 étapes, tandis que pour TEXTURE cela dépend de la taille de la texture.

À noter : l’exécution de Play ne s’annule pas, pas plus que l’enregistrement ou le chargement.

11-12. Objets 3D


nodegram propose deux façons d’afficher un objet 3D : Polygon et ARRAY + LINE (affichage 3D). Les deux ne se créent qu’en important un fichier .obj — impossible depuis CREATE NEW NODE.

nodegram lui-même reste néanmoins une plateforme 2D. Un objet 3D n’est qu’une manière d’utiliser une image d’allure 3D comme matériau 2D et, comme tout autre objet 2D, son ordre d’affichage vient de son réglage Sorting Layer. Les nœuds Polygon partageant un même Sorting Layer sont traités ensemble comme une seule scène 3D : leurs profondeurs se superposent donc correctement.

Les objets 3D possèdent une coordonnée Z. Le plan de l’écran est z=0, l’éloignement +z et le rapprochement −z. La distance du point de vue à l’écran et la hauteur du point de vue se règlent sur le nœud Setting.
Vous pouvez toujours établir des relations parent-enfant avec des objets 2D, mais il est alors conseillé de rester à z=0.

Pour un tracé en LINE (affichage 3D), remplissez l’ARRAY rattaché au nœud LINE avec une suite de triplets x,y,z. Tout ce qui précède un séparateur (9999,9999,9999) forme une ligne continue, et ce qui suit en commence une nouvelle (format : x,y,z, x,y,z, … 9999,9999,9999, x,y,z, … 9999,9999,9999). Un ARRAY peut avoir plusieurs nœuds LINE pour parents.

13. À savoir

  • Sur téléphone :
    Ajouter un raccourci nodegram à l’écran d’accueil permet de l’utiliser comme une application. Mais, comme pour une application, le supprimer (retirer le raccourci) effacera très probablement vos données enregistrées. Utilisez Export pour conserver vos programmes terminés dans des fichiers séparés.

    Sur certains navigateurs mobiles, l’affichage ou la position des touchers peuvent être décalés.
    Dans ce cas, quittez nodegram, fermez la tâche (ce n’est pas la même chose que supprimer l’application), tenez fermement le téléphone en mode paysage et relancez-le.
  • Enregistrement automatique :
    Tant que « auto save » est activé dans l’écran d’enregistrement, le dernier fichier utilisé est écrasé toutes les 30 secondes. Pour garder une copie distincte, utilisez Save et donnez-lui un nouveau nom.
