1. Was ist nodegram?

nodegram ist ein Werkzeug zum Programmieren mit Knoten.

Verbinden Sie einen Stick-Knoten mit einem Character-Knoten und die Figur bewegt sich bereits.



• Programmieren auf Smartphone oder PC.

• Lassen Sie andere die Spiele spielen, die Sie bauen.
• nodegram läuft im Web: Sie können überall programmieren, wo Sie eine Verbindung haben (ein nodegram-Programm ist nur etwa so groß wie ein einzelnes Bild).

Was ist Knotenprogrammierung (Node Programming)?
nodegram bietet über 40 Arten von Knoten – einen, der nur addiert, einen, der sich eine Zahl merkt, einen, der prüft, ob eine Taste gedrückt ist, und so weiter.

Bei der Knotenprogrammierung reichen Nodes einander Informationen weiter und erledigen so gemeinsam eine große Aufgabe. Jeder Node (ein Mitarbeiter) nimmt die Werte, die er von anderen Mitarbeitern bekommt, erledigt seine eigene Arbeit und gibt das Ergebnis weiter. Alle Nodes (Mitarbeiter) arbeiten ständig, jeder für sich.

Bei der üblichen textbasierten Programmierung dagegen liest ein einzelner Mitarbeiter die Anweisungen der Reihe nach und führt sie aus.

3. Erste Schritte

nodegram hat drei Ansichten:
Programmieren Sie Ihre Knoten im NodeEditor
Platzieren Sie Ihre Objekte im Layout
Führen Sie Ihr Programm in Play 

aus.

3-1. Knoten anlegen (NodeEditor)

  • Im NodeEditor halten Sie den Hintergrund gedrückt (die leere schwarze Fläche), um den Dialog „CREATE NEW NODE“ zu öffnen.


  • Wählen Sie einen Knoten aus der Liste, und er erscheint im NodeEditor.
  • Halten Sie einen Knoten gedrückt – oder doppelklicken Sie ihn –, um seinen Property-Dialog zu öffnen, in dem Sie ihn im Detail einstellen.
    Hier ändern Sie zum Beispiel die Farbe eines Objekts.
    Es gibt keine OK-Schaltfläche: Jede Änderung wirkt sofort. Schließen Sie den Dialog mit dem × oben rechts oder durch Tippen außerhalb.
    DUPLICATE kopiert den Knoten, DELETE löscht ihn.
  • Ziehen Sie einen Knoten (berühren und bewegen), um ihn zu verschieben.
  • Ziehen Sie vom Ausgangsport rechts an einem Knoten zu einem Eingangsport (links an einem anderen Knoten), um eine Verbindung herzustellen. Während der Ausführung fließen die Werte dann über diese Leitung vom roten zum blauen Anschluss.



  • Knoten mit einem Anschluss oben (Kindanschluss) lassen sich von dort mit einem Elternanschluss (unter einem anderen Knoten) verbinden. Beide bilden dann ein Eltern-Kind-Paar, und das Kind bewegt sich mit dem Elternteil.
    Bei einem Spieler, der schießt, machen Sie etwa die Mündung zum Kind und den Spieler zum Elternteil.

3-2. Objekte platzieren (Layout)

  • Mit der Schaltfläche „Layout“ wechseln Sie in die Layout-Ansicht.


  • Im Layout ordnen Sie Objektknoten wie Rect, Circle, Character und Text
    sowie Bedienknoten wie Button und Stick an.


  • Ziehen Sie ein Objekt, um es zu verschieben, nutzen Sie die weißen Griffe an den vier Ecken zum Skalieren und den runden Griff darüber zum Drehen.
  • Mit „NODE“ kehren Sie zum NodeEditor zurück.

3-3. Das Programm ausführen (Play)

  • Die Schaltfläche ▶ (Play) oben rechts im NodeEditor oder im Layout wechselt zu Play und startet das Programm.
  • Halten Sie die Schaltfläche □ (Stop) oben rechts in der Play-Ansicht gedrückt, um anzuhalten und zur Bearbeitung zurückzukehren.
  • In Play werden Objektknoten alle 1/60 Sekunde (ein Frame) gezeichnet und bewegen sich zusammen mit der Physiksimulation.
  • Gesteuert wird über den Bildschirm, den Joystick auf dem Display, die Tastatur oder die Maus.


  • Auch Schwerkraft lässt sich in der Play-Ansicht darstellen.
    Für ein Spiel im Stil von Flipper oder Mario schalten Sie Dynamics (Physik) ein.
    Fügen Sie einen Setting-Knoten hinzu und schalten Sie in dessen Property Dynamics ein, damit die Physik für das ganze Programm gilt.
    Jeder Objektknoten hat zusätzlich eine eigene Dynamics-Einstellung, die einzeln eingeschaltet werden muss.

5. MENU

Halten Sie die Schaltfläche MENU oben rechts gedrückt, ziehen Sie den Finger in Richtung eines Eintrags und lassen Sie los, um ihn auszuführen. Sie funktioniert auch als gewöhnliche Schaltfläche.

Die Schaltfläche ▶ oben rechts wechselt zu Play und startet das Programm.
Layout  wechselt in die Layout-Ansicht.

5-1. Die Menüeinträge

NEW NODE Öffnet CREATE NODE, um einen Knoten hinzuzufügen. Ein langer Druck auf den Hintergrund bewirkt dasselbe.
SAVE Speichert das aktuelle Programm unter einem Namen (siehe 5-2).
LOAD Lädt ein gespeichertes Programm (siehe 5-3).
UNDO Macht die letzte Aktion rückgängig.
REDO Stellt eine rückgängig gemachte Aktion wieder her.
FIT Passt Zoom und Position so an, dass alle Knoten auf den Bildschirm passen.
NEW Löscht alles und beginnt ein neues Programm.
SETTING Öffnet die Einstellungen der App selbst (siehe 5-4). Nicht zu verwechseln mit dem SETTING-Knoten.
OPEN HELP Öffnet diese Hilfeseite.

Während Sie innerhalb eines Compo arbeiten, wechseln die Einträge links zu den Compo-spezifischen. Diese beschreibt das Kapitel „Compo-Knoten“.

5-2. SAVE (Speichern)

Speichert das Programm unter einem Namen auf diesem Gerät. Ein bereits vorhandener Name wird überschrieben. Erlaubt sind lateinische Buchstaben, Ziffern und einige Sonderzeichen.
AUTO aktiviert das automatische Speichern: Danach wird alle 30 Sekunden gespeichert (nie während Play).
EXPORT schreibt das Programm als Datei heraus – praktisch für Sicherungen und zur Weitergabe.
Als Format stehen .ngz (gzip-komprimiert) und .json (Text) zur Wahl.
Benennen Sie eine .ngz-Datei einfach in .gz um, und jedes gewöhnliche Entpackprogramm holt das JSON heraus.

Sie können bis zu 256 Speicherstände behalten. Sie liegen im verwendeten Browser und sind daher von einem anderen Gerät oder Browser aus nicht sichtbar.
Die Speicherstände liegen innerhalb von nodegram: Löschen Sie die nodegram-Verknüpfung vom Smartphone, gehen sie womöglich mit verloren.
Für alles Wichtige verwenden Sie EXPORT und bewahren eine Datei auf.

5-3. LOAD (Laden)

Zeigt die Liste der gespeicherten Programme. Die Schaltfläche neben jedem Namen löscht ihn auch.
IMPORT lädt eine zuvor exportierte Datei. Es gibt zwei Arten zu laden: Laden ersetzt den aktuellen Inhalt, während Hinzufügen das laufende Programm behält und die Datei darunter anfügt.

Importieren Sie eine in 3D-Software erstellte .obj-Datei, kommt das Modell als POLYGON-Knoten herein oder als ARRAY-Knoten für einen LINE-Knoten (3D-Darstellung). Näheres unter 11-12. 3D-Objekte.

5-4. SETTING (App-Einstellungen)

Einstellungen der App selbst. Sie werden nicht im Programm gespeichert, sondern bleiben nur auf diesem Gerät.
Wire: wählt die Form der Leitungen (Kurve oder Gerade).
NodeColor: wählt das Farbschema der Knoten.
Language: ändert die Sprache der Oberfläche.
Japanisch, Englisch, Chinesisch (vereinfacht), Französisch, Deutsch, Hindi, Indonesisch, Italienisch, Koreanisch, Portugiesisch, Russisch, Spanisch, Thai, Türkisch und Vietnamesisch

Einstellungen je Szene wie FPS oder Dynamics finden sich nicht hier, sondern am SETTING-Knoten. Die Namen ähneln sich – verwechseln Sie beides nicht.

Auf dem Smartphone

    Mit einem Finger schieben, mit zwei Fingern zoomen. Langes Drücken, Doppeltippen und Ziehen und alles Weitere funktionieren wie am PC.

  • Drehen des Bildschirms:
    Die Ansicht folgt der Geräteausrichtung. Während Play gilt die am SETTING-Knoten festgelegte Ausrichtung (Horizontal oder Vertical); hält man das Gerät anders herum, erscheint ein Hinweis.
  • Hinweis für iOS: 
    Auf iPhone und anderen iOS-Geräten öffnen Sie das Safari-Menü und tippen ① und dann ②, um die Symbolleiste auszublenden. Das kommt einer Vollbildansicht nahe und macht nodegram deutlich angenehmer.
    Für echtes Vollbild öffnen Sie das Teilen-Menü von Safari und wählen „Zum Home-Bildschirm“. nodegram verhält sich dann wie eine App – das empfehlen wir.
    Beachten Sie: Löschen Sie dieses Symbol vom Home-Bildschirm, können auch Ihre gespeicherten Daten verschwinden. Exportieren Sie Wichtiges in einen Ordner auf dem Gerät.

7. Knoten-Referenz



Ein/Aus steht für die Zahl der Eingangs- bzw. Ausgangsanschlüsse.

Konstanten

Knoten Eingänge/Ausgänge Beschreibung
Constant 0/1 Gibt die unter Value eingestellte Zahl aus.

Rechnen

Knoten Ein/Aus Beschreibung
＋ 2/1 Gibt Eingang 1 + Eingang 2 aus.
Ein Additionsknoten ist nicht immer nötig: Jeder Eingang nimmt mehrere Leitungen auf und summiert sie, sodass zwei Leitungen an Eingang 1 bereits deren Summe ergeben.
－ 2/1 Gibt Eingang 1 − Eingang 2 aus
× 2/1 Gibt Eingang 1 × Eingang 2 aus
÷ 2/1 Gibt Eingang 1 ÷ Eingang 2 aus. Ist der Nenner 0, wird 0 ausgegeben.
√ 1/1 Gibt die Quadratwurzel von Eingang 1 aus. Bei einem Eingang von 0 oder weniger wird 0 zurückgegeben.
Compare 2/1 Vergleicht Eingang 1 mit Eingang 2 (=, >, <, ≠, ≥, ≤). Gibt 1 aus, wenn der Vergleich zutrifft, sonst 0.
Not ( ! ) 1/1 Gibt 1 aus, wenn Eingang 1 gleich 0 ist, sonst 0.
And 2/1 Gibt 1 aus, wenn Eingang 1 und Eingang 2 beide ungleich 0 sind, andernfalls 0.
Or 2/1 Gibt 1 aus, wenn Eingang 1 oder Eingang 2 ungleich 0 ist, und 0, wenn beide 0 sind.
Pos Angle 2/1 Position zu Winkel. Gibt ArcTan2(Eingang 2, Eingang 1) in Grad aus.
Angle Pos 1/2 Winkel zu Position. Gibt (cos, sin) für einen Winkel in Grad aus.
Random 1/1 Gibt eine ganze Zufallszahl von 0 bis unter Number aus. Ein neuer Wert entsteht beim Start von Play und in jedem Frame, in dem Eingang 1 ungleich 0 ist. Mit eingeschaltetem Use Seed und einem Seed-Wert wiederholt sich bei jedem Play dieselbe Folge.
Int 1/1 Wandelt in eine ganze Zahl um. Die Eigenschaft Round bietet Floor, Round und Integer.
Floor (Standard) nimmt die nächste ganze Zahl kleiner oder gleich dem Eingang: 2,8 wird zu 2 und −0,1 zu −1. Round rundet kaufmännisch, Integer behält nur den ganzzahligen Teil.

Werte und Zeitsteuerung

Knoten Ein/Aus Beschreibung
Trigger 1/1 Gibt für genau einen Frame 1 aus, sobald der Eingang von 0 auf einen anderen Wert wechselt.
DELAY(F) verzögert diese 1 um die angegebene Anzahl Frames.
Counter 2/1 Ein Zähler. Er addiert in jedem Frame Eingang 1, subtrahiert Eingang 2 und gibt den gespeicherten Wert aus.
Type = Clamp hält ihn zwischen Min und Max, Loop lässt ihn in diesem Bereich umlaufen. Value (Startwert), Min und Max sind einstellbar.
Var 2/1 Dient als Variable: Er hält eine einzelne Zahl und gibt sie aus.
Ist das Setzsignal an Eingang 2 ungleich 0, merkt er sich Eingang 1.
Ein Startwert lässt sich festlegen.
Array 3/1 Ein Knoten, der als Array dient.
Geben Sie an Eingang 2 einen Index an (die Position im Array, die erste ist 0), und er gibt den Wert an dieser Stelle aus. Die Zählung beginnt bei 0: Bei Länge 3 sind 0, 1 oder 2 möglich; unter 0 und ab 3 gibt es keinen Wert, und es wird 0 zurückgegeben.
Das Setzsignal an Eingang 3 überschreibt das Element am Index (Eingang 2) mit dem Wert von Eingang 1.
Trennen Sie die Startwerte durch Kommas „,“ oder Zeilenumbrüche.

Auf ein Array kann gleichzeitig zugegriffen werden: etwa den 1. und 3. Wert lesen und zugleich den 2. Wert setzen.
Dazu verketten Sie mehrere Arrays als Eltern und Kinder. Nur das oberste Array hält die Werte tatsächlich; die Arrays darunter sind nur Zugangsschnittstellen zu ihm. Bei gleichzeitigem Schreiben hat das Elternteil Vorrang. Nur das oberste Array kann an LINE / VOICE / SOUND gehängt werden.

Mit Sound- und Voice-Knoten dient ein Array als Notenblatt, mit einem Line-Knoten als Polylinie. Ein Array kann von mehreren Lines gemeinsam genutzt werden. Die Schaltflächen SEQUENCER / LINE in der Property öffnen den Noteneditor bzw. den Grafikeditor (Kapitel 8).
Außerdem speichert ein Array 3D-Drahtgitter (siehe 11-12. 3D-Objekte ).
GetPos 0/2 Liest die aktuelle X- und Y-Position des Elternobjekts. Umschaltbar zwischen WORLD und LOCAL.
GetRot 0/1 Gibt den aktuellen Winkel des Elternobjekts aus, gegen den Uhrzeigersinn positiv. Umschaltbar zwischen WORLD und LOCAL.
Velocity 0/2 Gibt die X- und Y-Geschwindigkeit des Elternobjekts pro Sekunde aus (Y positiv nach oben). Ein größerer Frames-Wert mittelt über mehr Frames und glättet die Anzeige.

Der Inhalt eines Arrays wird in eigenen Editoren bearbeitet: Die Schaltfläche SEQUENCER in der Property bearbeitet ihn als Noten, die Schaltfläche LINE als Polylinie. Zur Bedienung siehe 8. Editoren .


Ausgabe und Objekte

Knoten Ein/Aus Beschreibung
Text 2/0 Zeigt Text an. Ohne Verbindung erscheint der Text aus der Eigenschaft Text, mit Verbindung der übergebene Wert. Eingang 2 schaltet die Anzeige ein und aus. Zahlen werden an der sechsten Nachkommastelle gerundet und bis zur fünften angezeigt. Textfarbe, Layout und der Rahmen ringsum sind einstellbar.
Rect 3/0 Ein Rechteck. Bei ausgeschalteter Dynamics sind Eingang 1/2 die x/y-Position, bei eingeschalteter Dynamics eine äußere Kraft x,y. Eingang 3 blendet das Objekt ein und aus. Farbe, Rahmen, Tag, Größe, Drehung, Sorting Layer usw. sind einstellbar. Broken by 1–3 nennt die My Tags der Objekte, die dieses zerstören können.
Zu Dynamics und Tag siehe 11. Spezifikationen .
Circle 3/0 Ein Kreis. Abgesehen von der Form und der Eigenschaft Radius entsprechen Eingänge und Eigenschaften denen von RECT.
Character 3/0 Eine Figur, die laufen und springen kann. Eingang 1/2 sind die Bewegungsgeschwindigkeit; Eingang 3 springt in dem Moment, in dem er von 0 oder weniger auf einen positiven Wert wechselt.
Die Sprungkraft ist proportional zum Eingangswert und wirkt nur am Boden. Für Physik und Springen schalten Sie Dynamics sowohl in SETTING als auch im Character ein. Für eine Draufsicht lassen Sie Dynamics an und setzen Gravity auf 0. Flip spiegelt die Textur passend zur Blickrichtung, AutoRot dreht die Figur in Laufrichtung, und KeepOnScr hält sie im Bildschirm.
Sie hat einen Kind-Anschluss, kann aber nicht Kind eines Objekts werden. Als Elternteil ist nur WARP IN möglich.
Shot 1/1 Eingang 1 feuert ein Geschoss ab. Bullet Count ist die Zahl gleichzeitig vorhandener Geschosse. My Tag zerstört alles, dessen Broken by dazu passt, während Broken by 1–3 am SHOT-Knoten angibt, woran seine Geschosse verschwinden – nach Knotentyp oder Tag. Der Ausgang ist nur in den Frames 1, in denen tatsächlich geschossen wurde. Keep Off-Screen erhält Geschosse außerhalb des Bildschirms; ist die Obergrenze erreicht, verschwinden die ältesten.
Line 5/0 Zeichnet eine Linie von (X1,Y1) nach (X2,Y2). Ist Eingang 5 (SET) verbunden, wird die Form aktualisiert, wenn dort ein Wert ungleich 0 ankommt, und solange er 0 ist, bleibt die vorige Form erhalten. Ohne Verbindung wird jedes Frame aktualisiert.
Mit einem ARRAY als Kind werden Eingang 1–4 ignoriert: Das Array wird als x1,y1,x2,y2,… gelesen und als durchgehende Polylinie gezeichnet. x=9999, y=9999 unterbricht die Linie. Coord wählt WORLD oder LOCAL.
Enthält das Kind-ARRAY 3D-Daten (x,y,z-Tripel), wird es automatisch als 3D LINEgezeichnet. Einzelheiten in Kapitel 8, LINE-Editor.
Sound 4/2 Eingang 1 ist das Wiedergabesignal, Eingang 2 die Tonhöhe (Do=0, Re=1 …), Eingang 3 die Lautstärke. Sind Eingang 2/3 nicht verbunden, gelten die Eigenschaften Tone/Volume. Gehaltene Klänge spielen, solange Signal (Eingang 1) nicht 0 ist; abklingende Klänge und Effekte spielen einmal bei der steigenden Flanke von Signal oder bei einem Tonhöhenwechsel. Tonhöhe 99 ist eine Pause. Die Eigenschaft Tone läuft in 0,5-Schritten (Halbton), Eingang 2 nimmt aber stufenlose Dezimalwerte.
Mit Chromatic wird Tone zu einer Halbtonnummer mit 12 Stufen (0=C, 1=Cis, 2=D …). Ohne Chromatic hat die Leiter 7 Stufen, und 0,5 ist eine schwarze Taste. Liefert ein Array die Tonhöhe, stellen Sie Chromatic wie im SEQUENCER des Arrays ein, sonst stimmen die Töne nicht.
Eingang 4 Pan legt die Stereo-Verteilung links/rechts zwischen −1 und +1 fest.

Hängen Sie ein Array direkt als Kind an, spielt dieser Sound die Noten selbst ab. Dann erscheinen die Eigenschaften Tempo (BPM) und Loop, und Eingang 2 wird statt der Tonhöhe zur Transposition (1 = ein Halbton). Ausgang 1 ist ein Signal, das am Ende der Wiedergabe für ein Frame 1 ist, Ausgang 2 die Zeit in Sekunden seit dem Start – damit lassen sich andere Knoten mit der Musik synchronisieren. Eingang 1 startet, 0 stoppt, und wieder ungleich 0 beginnt von vorn.
Der Array-Wert 90 ist ein Haltebogen („vorige Note fortsetzen“); so unterscheidet man einen erneut angeschlagenen gleichen Ton von einem gehaltenen.
Mit der Schaltfläche „Sequencer“ des am Sound hängenden Arrays bearbeiten Sie die Noten. Einzelheiten in Kapitel 8, Sequencer.
Voice 3/2 Ein Knoten, der japanische Kana spricht. Schreiben Sie Hiragana (Katakana gehen auch) in die Eigenschaft Line; die Stimme wird sofort synthetisiert (Formantsynthese).
Eingang 1 ist das Wiedergabesignal: Die steigende Flanke startet das Vorlesen von vorn, zurück auf 0 stoppt es auch mittendrin. Eingang 2 ist die Lautstärke.
Ausgang 1 ist ein Signal, das am Ende für ein Frame 1 ist, Ausgang 2 die Zeit in Sekunden seit dem Start. Geteilt durch die Länge einer Spalte ergibt sie die gerade gespielte Note – nützlich, um Begleitung oder Untertitel mit dem Gesang zu synchronisieren. Die Notennummer ist „Time × BPM ÷ 30“.
Als Stimme wählen Sie Girl / Boy / Woman / Man / Child / Plain / Robot. Pitch verschiebt sie in Halbtönen.
Eingang 3 Pan legt die Stereo-Verteilung links/rechts zwischen −1 und +1 fest.

Mit einem Array als Kind wird gesungen. Die Kana werden einzeln den Noten zugeordnet, Tempo (BPM) bestimmt die Geschwindigkeit. Ohne Array bestimmt Speed (Millisekunden pro Kana) statt Tempo das Sprechtempo.
Regel: ein Kana pro Note. Haltebögen (90) und Pausen (99) verbrauchen kein Kana. Beim Singen werden „、“ und „。“ übersprungen. Der Dehnungsstrich „ー“belegt eine eigene Note und kann den vorigen Vokal haltend zu einer anderen Tonhöhe wechseln (Legato).
Noten ohne verfügbares Kana werden zu einem roten „·“ und bleiben stumm.
Den Text bearbeiten Sie in den Eigenschaften von Voice, die Tonhöhen im SEQUENCER des Arrays; die Schaltflächen → ARRAY ／ → VOICE wechseln zwischen beiden.
Einzelheiten in Kapitel 8 , Sequencer.
Polygon 7/0 Ein Objekt, das die Flächen (Polygone) eines 3D-Modells anzeigt. Es lässt sich nicht über CREATE NEW NODE erzeugen, sondern entsteht nur beim IMPORT einer .obj-Datei.
Seine Eingänge sind eine 3D-Position, eine 3D-Drehung und eine Skalierung.
Einzelheiten in 11-12. 3D-Objekte .

Bedienung

Knoten Ein/Aus Beschreibung
Stick 1/2 Ein Joystick auf dem Bildschirm. Ausgang 1 ist die waagerechte Neigung des Sticks, Ausgang 2 die senkrechte. Analog oder digital, zudem auf Tastatur oder Gamepad legbar.
Button 1/1 Virtuelle Schaltfläche. 1, solange sie gedrückt ist. Kann Tastatur oder Gamepad zugeordnet werden.

  Weitere Knoten

Knoten Ein/Aus Beschreibung
TEXTURE 1/0 Enthält eine Pixelgrafik, die Sie zeichnen, und legt sie auf das als Elternteil gesetzte Objekt. Zuweisbar an Rect, Circle, Chara, Shot und BG, und mit mehreren Elternteilen (mehreren Objektknoten) möglich.

SENSOR 0/1 Gibt aus, wie viele Objekte den Sensorbereich überlappen (den in der Layout-Ansicht festgelegten Bereich). Ein Objekt zählt, wenn es die Target-Bedingung oder einen der Tags 1–3 erfüllt, und jedes Objekt wird nur einmal gezählt, auch wenn es mehrere davon erfüllt. Target=SCREEN gibt stattdessen 0 oder 1 zurück, je nachdem, ob der Sensorbereich den sichtbaren Bildschirm überlappt. B. per Eingang einen Effekt aufleuchten lassen und gleichzeitig einen Klang abspielen). Effektart (NONE, PARTICLE, LINE, CIRCLE, BOX) und Farbe sind einstellbar.
ROTATE 1/0 Ein Scharnier zum Drehen einer Eltern-Kind-Gruppe. Ein Objekt mit ROTATE als Elternteil übernimmt dessen Position und Drehung. Eingang 1 ist der Drehversatz gegenüber dem im Layout eingestellten Winkel, positive Werte drehen gegen den Uhrzeigersinn.
SCREEN 3/2 Steuert die Kamera während Play. X/Y sind die Kameraposition (bei vorhandenem Elternteil ein Versatz dazu; Y positiv nach oben) und S der Zoom mit einem Minimum von 0,05. Ein Objekt mit SCREEN als Elternteil wird zu einem festen HUD, das die Kamera nicht beeinflusst.
Setzen Sie das Spielerobjekt als Elternteil von SCREEN, folgt die Ansicht dem Spieler.
RESTART 1/1 Wechselt der Eingang von 0 auf einen anderen Wert, kehrt das ganze Programm in den Zustand beim Start von Play zurück. Positionen, Variablen, Zähler, Arrays, Geschosse und so weiter werden zurückgesetzt. Der Wert, der den Neustart ausgelöst hat, bleibt danach am Ausgang erhalten – praktisch, um Leben oder Punktestand zu übernehmen.
COMPO 3/3 Ein Bauteil, das mehrere Knoten zu einem zusammenfasst. E = aktiv/inaktiv, 1 und 2 = Austausch mit dem Inneren.

8. Editoren

Eigene Bearbeitungsfenster, die aus der Property eines Knotens geöffnet werden. LINE und SEQUENCER erstellen den Inhalt eines Array-Knotens, TEXTURE den eines Texture-Knotens. Jeder Editor schließt mit dem × oben rechts, und beim Schließen wird der Inhalt in den Knoten geschrieben. ◁ / ▷ machen in jedem Editor rückgängig bzw. wiederholen.

8-1. LINE-Editor

Ein Werkzeug zum Zeichnen der Polylinie für einen Line-Knoten. Öffnen Sie es über die Schaltfläche LINE in der Property eines Array-Knotens.
Der Ursprung liegt in der Mitte des Bearbeitungsbereichs; X ist nach rechts positiv, Y nach oben, jeweils von -99 bis 99.
DRAW zeichnet die Polylinie. Während des Zeichnens wird die Schaltfläche DRAW zu Endpoint; ein Druck darauf beendet den Strich.
MOVE verschiebt einen Eckpunkt, ERASE löscht ein einzelnes Segment, VIEW verschiebt die Ansicht.
Beim Schließen wird die Zeichnung zu einer Folge von x,y-Zahlen; x,y = (9999,9999) unterbricht die Linie.

Setzen Sie einen Line-Knoten als Elternteil eines Array-Knotens, zeichnet der Line den Inhalt dieses Arrays. Ein Array kann auch mehrere Line-Knoten als Eltern haben.

8-2. SEQUENCER-Editor

Ein Werkzeug, um die Noten (ein Array) für Sound- oder Voice-Knoten zu erstellen. Öffnen Sie es über die Schaltfläche SEQUENCER in der Property eines Array-Knotens.
1 Spalte = eine Achtelnote, 1 Takt = 8 Spalten, bis zu 500 Takte, 6 Oktaven (3 unter und 3 über dem mittleren C). Drei Oktaven sind gleichzeitig sichtbar; den Rest sehen Sie durch senkrechtes Scrollen.

・Modi

DRAWTippen oder ziehen Sie auf einer leeren Stelle, um Noten zu setzen. Tippen auf eine Note ändert ihre Tonhöhe, Ziehen verschiebt sie.
ERASEZiehen löscht fortlaufend. Berühren Sie eine Note an beliebiger Stelle, wird die ganze Note gelöscht.
RESIZEÄndert nur die Länge einer Note. Ziehen Sie eine Note, und ihr rechtes Ende wächst oder schrumpft um die Zahl der überfahrenen Spalten.
Copy / PasteKopiert einen Spaltenbereich und fügt ihn ein. Wird die Einfügeposition nach oben oder unten verschoben, wird transponiert.
VIEWVerschiebt die Ansicht. Zoomen per Pinch oder Mausrad; Ziehen mit der mittleren Taste verschiebt auch senkrecht.

・ Notenlänge, Haltebogen und Legato

Eine Note, geschrieben als „Tonhöhenwert, 90, 90, 90“, dauert 4 Spalten. 90 ist ein Haltebogen („vorige Note fortsetzen“) und wird automatisch eingetragen, wenn Sie eine Note mit RESIZE verlängern.

Mit anderen Worten: denselben Ton zweimal spielen und einen Ton halten unterscheiden sich nur darin, ob der zweite Wert eine Tonhöhe oder 90 ist.

0,0Zwei Achtelnoten C: C, C
0,90Eine Viertelnote C
99Pause
Bei Voice klingen zwei Achtel, gesungen als „ド“ und Dehnungsstrich „ー“, jedoch wie eine Viertelnote C.
Da „ド“ und „ー“ getrennte Noten sind, können Sie ihnen auch verschiedene Tonhöhen geben; das ergibt ein Legato (Übergang zu einer anderen Tonhöhe ohne Absetzen).

・ Tonhöhenwerte

C ist 0, D ist 1 und Cis ist 0,5.
Der Takt mit der letzten Note wird bis zu seinem Ende mit Pausen (99 im Array) aufgefüllt.
Mit CHROMATIC wird jedes Feld zu einem Halbton (C=0, C♯=1, D=2, D♯=3, E=4, F=5, F♯=6, G=7, G♯=8, A=9, A♯=10, H=11), eine Oktave umfasst also 12. Beim Umschalten von CHROMATIC werden auch die Zahlen im Array und die Chromatic-Einstellung der verbundenen Sound-Knoten umgerechnet.
Mit MAJOR lassen sich nur weiße Tasten setzen (vorhandene Noten auf schwarzen Tasten bleiben erhalten).

・Sound / Voice -Knoten

Ist das Array Kind eines Sound oder Voice, sind BPM und Source (das Instrument) ein gemeinsamer Wert für alle, die dieses Array nutzen. Sie lassen sich im Sequencer oder in der Property des Elternknotens ändern; so oder so ändert sich alles zusammen. CHROMATIC gehört nur dann zum Sound, wenn ein Sound das Elternteil ist, und kann im Sequencer nicht geändert werden. Die Schaltflächen → SOUND ／ → VOICE unten links führen zu diesem Elternknoten.
Bei einem Array ohne Elternteil sind BPM und Instrument Einstellungen nur dieses Arrays.

・ Probehören

Die Wiedergabetaste spielt die Noten ab. Tippen Sie während der Wiedergabe auf eine Spalte, springt die Wiedergabeposition dorthin.
Ein mit einem Voice-Knoten verbundener Sequencer zeigt die Kana des Liedtexts über den Noten.

Ein Array allein erzeugt im Spiel keinen Ton. Kombinieren Sie es mit Sound oder Voice.


▶ Beispiel öffnen: „Hana“ (Haru no urara no Sumidagawa)


・ Mehrere Sequenzen gemeinsam bearbeiten

Wählen Sie im NodeEditor mehrere Array-Knoten aus, halten Sie einen gedrückt und wählen Sie „SEQUENCER“: Bis zu 7 davon lassen sich im selben Raster bearbeiten.
Tippen auf eine Nummernschaltfläche wechselt das bearbeitete Array, Gedrückthalten öffnet Lautstärke und Stummschaltung, Ziehen ändert die Reihenfolge. Farbe und Instrument sind je Array einstellbar.

8-3. TEXTURE-Editor

Öffnen Sie ihn über die Schaltfläche „Edit Texture“ in der Property eines Texture-Knotens. Zeichnen Sie Pixelgrafik; sie wird auf das als Elternteil gesetzte Objekt gelegt.

PaintFüllt einen zusammenhängenden Bereich gleicher Farbe.
PickNimmt eine Farbe aus dem Bild auf und macht sie zur aktuellen Farbe.

◁ / ▷UNDO / REDO

Wählen Sie eine Farbe aus der Palette unten. Zum Löschen wählen Sie die transparente Farbe und zeichnen damit. Halten Sie ein Palettenfeld gedrückt, um eine beliebige Farbe zu wählen.

9. Compo-Knoten

  • Ein besonderer Knoten, mit dem sich eine Gruppe von Knoten wie ein einziger behandeln lässt.

    Angenommen, dieselbe Knotenkombination taucht zehnmal in Ihrem Programm auf – dann möchte man sie einmal bauen und wiederverwenden.
    In nodegram bündeln Sie dazu mehrere Knoten zu einem Compo-Knoten und duplizieren diesen.

    Für zehn gleiche Gegner bauen Sie einen davon, bündeln seine Knoten zu einem Compo, duplizieren das Compo und platzieren die Kopien im Layout.

    Duplizierte Compo-Knoten teilen sich ein und dasselbe Programm: Ändern Sie eines, ändern sich auch die anderen – doch jede Kopie behält während der Ausführung eigene Koordinaten, Variablen, Lebensdauer und so weiter.

  • Einen Compo-Knoten anlegen
  1. Wählen Sie die Knoten aus, die zusammengefasst werden sollen.
    Für eine Mehrfachauswahl doppelklicken und ziehen Sie.
    Halten Sie beim zweiten Klick die Taste gedrückt und ziehen Sie einen Auswahlrahmen auf.
    Auf dem Smartphone fühlt es sich an wie „tipp, tipp-halten, streichen“.
    (In diesem Beispiel steht der Spieler links, und der umrahmte Bereich ist das Programm für einen Gegner, der sich ihm nähert.)



  2. Halten Sie bei mehreren ausgewählten Knoten einen davon gedrückt, um das Menü zu öffnen. Wählen Sie „MAKE COMPO“ und bestätigen Sie mit „Yes“.




  3. Aus den Knoten ist ein einzelner Compo-Knoten namens „C1“ geworden.


  4. Halten Sie C1 gedrückt (oder doppelklicken Sie), um hineinzugehen und das Compo in einem eigenen NodeEditor zu bearbeiten.
    Die Leitungen, die ins Compo führten, erscheinen nun als OUT-Knoten namens „C1 1“ und „C1 2“.

    Drücken Sie rechts „MENU“: Die linke Spalte enthält jetzt die Compo-Befehle.
    „Duplicate“ erzeugt eine Kopie dieses Compo-Knotens.
    Die Schaltfläche „PARENT“ unten rechts verlässt diesen NodeEditor und kehrt zum darüberliegenden zurück.



  5. Im übergeordneten NodeEditor sehen Sie, dass es nun mehrere Compo-Knoten gibt.
    Auch „C1 (2)“ soll denselben Eingangswert bekommen – verdrahten Sie es also genauso.



  6. Drücken Sie „LAYOUT“ und platzieren Sie jedes Compo dort, wo Sie es haben möchten.


  7. Drücken Sie Play „▶“: Es gibt mehrere Gegner, und jeder bewegt sich für sich.

  8. Für viele Kopien auf einmal wählen Sie die Compo-Knoten zusammen aus, halten einen davon gedrückt und wählen „Duplicate“.
    Sollen alle Compo denselben Wert erhalten, sind IN- und OUT-Knoten der bequeme Weg dorthin.


  • Compo-Knoten und Instanzen

    Enthalten zwei Compo-Knoten dasselbe Programm, sodass eine Änderung am einen auch den anderen verändert, sagt man, die beiden seien Instanzen voneinander; ein Compo zu duplizieren heißt, „eine Instanz davon anzulegen“.
    Compo-Knoten mit derselben Compo-Nummer sind Instanzen voneinander und teilen sich ein Programm.
    (Diese Verbindung zu lösen heißt Unique und findet sich im Wischmenü des Compo. Siehe unten)

    Die Zahl nach dem C sagt, um welches Compo es geht: gleiche Zahl, gleiche Instanzen desselben Compo.
    „C1 (1)“ und „C1 (2)“ sind Instanzen voneinander.
    „C1 (1)“ und „C2 (1)“ sind verschiedene Compos ohne Beziehung zueinander.
    Die Zahl in Klammern unterscheidet lediglich die Kopien eines Compo.

    Auch wenn Compos Instanzen voneinander sind, wird während Play jeder Parameter getrennt behandelt.
    Entstehen und Verschwinden, Koordinaten sowie die Knoten count, var und array im Inneren behalten je eigene Werte.

  • Das MENU innerhalb eines Compo-Knotens


    Duplicate und Delete: Compo-Knoten duplizieren oder löschen.

    Unique    : löst die Verbindung dieses Compo zu seinen Instanzen. Nützlich, wenn Sie eine Kopie eines Compo zu einem anderen Gegner umbauen wollen. Die Kopie erhält eine neue Compo-Nummer.

    Expand    : holt die Knoten aus dem gerade bearbeiteten Compo zurück in den Haupt-NodeEditor; das Compo selbst verschwindet. Es ist die Umkehrung von Make Compo. Compos, die Instanzen davon sind, werden nicht mit expandiert.

  • Compo-Knoten mit IN- und OUT-Knoten

    Ein Compo-Knoten hat nur zwei Eingangs- und zwei Ausgangsanschlüsse, doch mit IN- und OUT-Knoten kommen weitere hinzu.
    IN- und OUT-Knoten tragen in ihren Eigenschaften eine Compo-Nummer, sodass sich ein Wert an ein bestimmtes Compo liefern lässt.


    Innerhalb eines Compo dürfen Sie einen OUT-Knoten ohne Compo-Nummer verwenden.
    Innerhalb eines Compo ist ein IN-Knoten ohne Compo-Nummer nicht möglich, da zwei gleiche IN-Knoten nicht erlaubt sind.

    Achtung: Ein IN- oder OUT-Knoten mit Compo-Nummer bedeutet etwas völlig anderes, je nachdem, ob er innerhalb oder außerhalb des Compo liegt.
    Im Bild oben erscheint der blaue „IN-Knoten: C1, Index 2“ sowohl innerhalb als auch außerhalb des Compo, und beide sind nicht dasselbe. Der innere hängt am Ausgang 2 des Compo, während der äußere am Eingang 2 des Compo hängt und seinen Wert an den „OUT-Knoten: C1, Index 2“ im Inneren weitergibt.

  • Der Enable-Eingang und -Ausgang eines Compo

    Verwenden Sie einen Compo-Knoten als Spielfigur, steuern Enable-Eingang und -Ausgang, wann diese Figur erscheint und verschwindet.

    Der Enable-Ausgang ist 1, solange die Figur existiert, und wird 0, sobald sie zerstört ist.

    Wechselt der Enable-Eingang von 0 auf 1 (oder einen anderen Wert ungleich 0), startet das Programm im Compo und die Figur wird aktiv. Sie bleibt nur am Leben, solange dieser Eingang ungleich 0 bleibt: Fällt er auf 0 zurück oder wird die Figur zerstört, verschwindet sie.
    Ist am Enable-Eingang nichts angeschlossen, verhält es sich, als läge dort dauerhaft 1 an.

    Selbst eine verschwundene Figur beginnt wieder im Ausgangszustand, sobald der Eingang erneut von 0 auf einen anderen Wert wechselt.
    Unten sehen Sie ein Programm, das die Figur drei Sekunden nach ihrer Zerstörung an der Startposition wieder erscheinen lässt.


  • Ein Elternteil je Compo-Knoten

    Innerhalb eines Compo darf die Eltern-Kind-Kette der Objekte nicht mehr als ein oberstes Elternobjekt enthalten. Zwei Figuren in einem einzigen Compo-Knoten sind nicht vorgesehen.
    Zwei Elternteile sind unproblematisch, solange beide einen gemeinsamen Elternteil darüber haben.
    Gar kein Objektknoten (und damit kein Elternteil) ist ebenfalls unproblematisch.


  • Knoten, die sich nicht in einem Compo anlegen lassen

    BG, Setting, Stick, Button, Screen und OnBreak lassen sich nicht in einem Compo anlegen.

11. Spezifikationen

11-1. Nur 2D

nodegram ist reines 2D. Es gibt zwei Achsen: X (nach rechts positiv) und Y (nach oben positiv). Schalten Sie im Setting-Knoten Dynamics ein, fallen Figuren zum unteren Bildschirmrand.
Für ein Spiel in Draufsicht schalten Sie Dynamics im SETTING-Knoten aus oder setzen die Schwerkraft des ganzen Spiels auf 0.
Polygone und 3D-Drahtgitter sind ebenfalls nutzbar, werden aber als 2D-Objekte behandelt, die sich dreidimensional darstellen lassen.

11-2. FPS

Wählen Sie am SETTING-Knoten eine Ziel-Bildrate von 60 oder 30 (Standard 60). Sowohl die Auswertung der Knoten als auch die Physik laufen in diesem Takt. Wird ein Programm zu schwer, verlangsamt sich Play und die tatsächliche Bildrate fällt unter den eingestellten Wert.

11-3. Dynamics (Physik)

Objekte wie Rect, Circle, Character und Shot lassen sich mit einem Physikmodus (Dynamics) versehen. Das Verhalten entspricht weitgehend Unitys Rigidbody2D.

Modus Verhalten
Off Keine Physik. Die Knoteneingänge (X,Y) verschieben das Objekt einfach.
Static Eine unbewegliche Wand oder ein Boden. Schwerkraft und Kollisionen bewegen ihn nicht.
Dynamic Bewegt sich physikalisch unter Schwerkraft und Kollisionen. Die X/Y-Eingänge des Knotens wirken als Kraft.
Kinematic Schwerkraft und Kollisionen bewegen ihn nicht, Knoteneingaben schon; er kollidiert dennoch mit Dynamic-Objekten und schiebt sie.

Eine Dichteangabe gibt es nicht; alles wird ungefähr wie Holz behandelt.

11-4. SortingLayer (Zeichenreihenfolge)

Der SortingLayer jedes Objekts (0–100, Standard 50) bestimmt die Stapelreihenfolge in der Play-Ansicht. Je höher die Zahl, desto weiter vorne wird gezeichnet. BG (der Hintergrund) liegt stets ganz hinten.
Objekte mit gleichem Wert erscheinen in der Reihenfolge ihres Hinzufügens.

11-5. Koordinaten

  • X ist positiv nach rechts und Y positiv nach oben. Die Mitte der Layout-Ansicht ist der Ursprung (0,0).
  • Winkel werden in Grad angegeben, und gegen den Uhrzeigersinn ist positiv. 0° ist rechts (X+), 90° oben (Y+), 180° links (X−) und 270° unten (Y−). ANGLE POS, POS ANGLE, GetRot, ROTATE und die Eigenschaft Angle eines Objekts folgen alle dieser Konvention.
  • Die Eigenschaft Coord eines Objekts ändert die Bedeutung der X/Y-Eingänge.
    • WORLD: Der Eingang ist eine absolute Position (relativ zum Elternteil, falls vorhanden).
    • LOCAL: Der Eingang ist ein Versatz gegenüber der ursprünglichen Platzierung. Mit einem Elternteil kommt der Versatz zu diesem hinzu (Elternkoordinaten).
  • Zu den Koordinaten von 3D-Objekten siehe 11-12. 3D-Objekte.

11-6. Auflösung

Der während Play sichtbare Bereich entspricht dem grauen Rechteck im Layout.
Die Ausrichtung (Horizontal oder Vertical) stellen Sie am SETTING-Knoten ein – nicht im Setting-Menü – und die Anzeige passt sich der tatsächlichen Bildschirmgröße an.
Für eine feste Auflösung verwenden Sie ScreenSize am Setting-Knoten.

11-7. Tag

Ein Tag ist eine Gruppe.
Sie könnten etwa allen kleinen Gegnern den Tag „Enemy_tiny“ geben oder mit „bg_destroyed“ und „bg“ zerstörbare von fester Kulisse unterscheiden.
Die Knoten Shot, OnBreak, Rect, Circle und Character verwenden alle Tags.


11-8. Knoten


  • Ein Eingang nimmt mehrere Leitungen zugleich auf, und der Knoten erhält deren Summe. Im Bild bekommt der oberste Anschluss 10+20 = 30.

  • Eine Eltern-Kind-Verbindung zwischen Knoten (vom oberen Anschluss zu einem unteren) dient nicht nur dazu, Objekte gemeinsam zu bewegen: Sie drückt auch eine Beziehung aus.
    So hängt ein Texture-Knoten an einem Objektknoten, ein OnBreak-Knoten an dem Objekt, das er überwacht, und ein Array-Knoten an einem Line-Knoten.
    Normalerweise kann ein Elternteil mehrere Kinder haben, ein Kind aber nur einen Elternteil.
    Die Knoten Texture, OnBreak und Array bilden die Ausnahme: Sie können jeweils mehrere Elternteile haben.


11-9. Mehrfachknoten-Menü


Doppelklicken und beim zweiten Klick ziehen, um mehrere Knoten mit einem Rahmen gleichzeitig auszuwählen. Mit mehreren ausgewählten Knoten ist Folgendes möglich.

PROPERTYErscheint, wenn alle ausgewählten Knoten vom selben Typ sind. Praktisch, um die Property aller gemeinsam zu ändern.
MAKE COMPOMacht aus den Knoten ein Compo. Siehe 9. Compo-Knoten.
DUPLICATEDupliziert alle ausgewählten Knoten.
DELETELöscht alle ausgewählten Knoten.

11-10. Was in einem Frame geschieht

Alle Knoten werden gleichzeitig verarbeitet.
Die Reihenfolge, in der Sie sie angelegt haben, ändert das Ergebnis nie.

Objektknoten und dergleichen werden einmal pro Frame verarbeitet.
Knoten, die sich einen Wert merken – Counter, Var, Trigger, Random, Array –, werden ebenfalls nur einmal pro Frame aktualisiert.
Rechenknoten wie + und × merken sich nichts; sie werden ausgewertet, wenn ihr Wert gebraucht wird.
Bilden Rechenknoten dennoch eine Schleife, wird jeder Knoten innerhalb eines Frames trotzdem nur einmal verarbeitet.

11-11. UNDO / REDO

Mit UNDO / REDO im MENU machen Sie das Anlegen, Löschen, Verschieben, Verdrahten, Ändern von Eigenschaften und so weiter rückgängig oder stellen es wieder her. Sie können bis zu 50 Schritte zurückgehen.

Die Editoren TEXTURE, LINE und SEQUENCER führen je einen eigenen Undo-Verlauf; nutzen Sie darin die Schaltflächen ◁ / ▷. LINE-Editor und SEQUENCER gehen ebenfalls 50 Schritte zurück, bei TEXTURE hängt es von der Texturgröße ab.

Beachten Sie: Das Ausführen von Play lässt sich nicht rückgängig machen, Speichern und Laden ebenso wenig.

11-12. 3D-Objekte


nodegram bietet zwei Wege, ein 3D-Objekt anzuzeigen: Polygon und ARRAY + LINE (3D-Darstellung). Beide entstehen nur beim Import einer .obj-Datei – über CREATE NEW NODE ist das nicht möglich.

nodegram selbst bleibt allerdings eine reine 2D-Plattform. Ein 3D-Objekt ist nur eine Art, ein 3D-anmutendes Bild als 2D-Material zu nutzen, und wie bei jedem anderen 2D-Objekt ergibt sich die Zeichenreihenfolge aus seiner Einstellung Sorting Layer. Polygon-Knoten mit gleichem Sorting Layer werden gemeinsam als eine 3D-Szene verarbeitet und überlagern einander daher tiefenrichtig.

3D-Objekte besitzen eine Z-Koordinate. Die Bildschirmebene ist z=0, weiter weg ist +z und zum Betrachter hin −z. Abstand des Blickpunkts zum Bildschirm und dessen Höhe stellen Sie am Setting-Knoten ein.
Eltern-Kind-Beziehungen mit 2D-Objekten sind weiterhin möglich, dann empfiehlt sich jedoch z=0.

Für eine Darstellung als LINE (3D) füllen Sie das an den LINE-Knoten gehängte ARRAY mit einer Folge von x,y,z-Tripeln. Alles bis zu einem Trenner (9999,9999,9999) wird zu einer durchgehenden Linie verbunden, was danach folgt, beginnt eine neue (Format: x,y,z, x,y,z, … 9999,9999,9999, x,y,z, … 9999,9999,9999). Ein ARRAY kann mehrere LINE-Knoten als Elternteile haben.

13. Wissenswertes

  • Auf dem Smartphone:
    Legen Sie eine nodegram-Verknüpfung auf den Home-Bildschirm, lässt es sich wie eine App nutzen. Doch wie bei einer App löscht das Entfernen (der Verknüpfung) sehr wahrscheinlich auch Ihre gespeicherten Daten. Sichern Sie fertige Programme mit Export als eigene Dateien.

    In manchen mobilen Browsern können Anzeige oder Berührungspunkte verrutschen.
