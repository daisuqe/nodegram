1. Apa itu nodegram

nodegram adalah alat untuk memprogram dengan node.

Cukup hubungkan node Stick ke node Character, dan karakter itu sudah bisa bergerak.



• Anda bisa memprogram di ponsel maupun di PC.

• Anda bisa membagikan game buatan Anda untuk dimainkan orang lain.
• nodegram berjalan di web, jadi Anda bisa memprogram di mana saja selama ada koneksi (ukuran sebuah program nodegram kira-kira hanya sebesar satu gambar).

Apa itu pemrograman node (Node Programming)
nodegram menyediakan lebih dari 40 jenis node: node yang hanya menjumlahkan, node yang mengingat sebuah angka, node yang memeriksa apakah sebuah tombol ditekan, dan seterusnya.
Pemrograman node ibarat sekelompok pekerja (node) yang saling mengoper informasi untuk menuntaskan satu pekerjaan besar. Setiap pekerja menerima nilai dari pekerja sebelumnya, mengerjakan bagian kecilnya, lalu meneruskan hasilnya. Semuanya bekerja tanpa henti.
Sebaliknya, pemrograman berbasis teks bekerja lain: satu pekerja membaca perintah satu per satu dan menjalankannya secara berurutan.

2. Memulai


Cara membuat game tembak-tembakan (2 menit)

nodegram punya tiga tampilan:
tempat menyusun program, NodeEditor
tempat menata objek, Layout
dan Play 

tempat program dijalankan.

2-1. Membuat node (NodeEditor)

  • Di NodeEditor, tekan lama latar belakang (area hitam kosong) untuk membuka dialog “CREATE NEW NODE”.


  • Pilih node yang Anda inginkan dari daftar, dan node itu akan muncul di NodeEditor.
  • Tekan lama sebuah node — atau klik ganda — untuk membuka dialog Property tempat Anda mengaturnya secara rinci.
    Di sinilah Anda mengubah hal seperti warna sebuah objek.
    Tidak ada tombol OK: setiap perubahan langsung berlaku. Tutup dialog dengan × di kanan atas atau dengan menyentuh di luar dialog.
    DUPLICATE menyalin node, DELETE menghapusnya.
  • Seret sebuah node (sentuh lalu geser) untuk memindahkannya.
  • Seret dari port keluaran di sisi kanan sebuah node ke port masukan (di sisi kiri node lain) untuk menyambungkan kabel. Setelah tersambung, nilai akan mengalir lewat kabel itu dari ujung merah ke ujung biru saat program berjalan.



  • Node yang punya konektor di bagian atas (konektor anak) dapat disambungkan dari sana ke konektor induk (di bawah node lain). Keduanya lalu menjadi pasangan induk-anak, dan sang anak ikut bergerak bersama induknya.
    Misalnya untuk pemain yang menembak, jadikan moncong tembakan sebagai anak dan pemain sebagai induk.

2-2. Menata objek (tampilan Layout)

  • Tekan tombol “Layout” untuk berpindah ke tampilan Layout.


  • Di Layout Anda menata node objek seperti Rect, Circle, Character, dan Text
    , serta node kendali seperti Button dan Stick.


  • Seret objek untuk memindahkannya, gunakan pegangan putih di keempat sudut untuk mengubah ukurannya, dan pegangan bulat di atasnya untuk memutarnya.
  • Tekan “NODE” untuk kembali ke NodeEditor.

2-3. Menjalankan program (tampilan Play)

  • Tombol ▶ (Play) di kanan atas NodeEditor atau Layout akan berpindah ke Play dan menjalankan program.
  • Tekan lama tombol □ (Stop) di kanan atas tampilan Play untuk berhenti dan kembali menyunting.
  • Di Play, node objek digambar setiap 1/60 detik (satu frame) dan bergerak mengikuti simulasi fisika.
  • Anda dapat mengendalikannya lewat sentuhan layar, JoyStick di layar, papan ketik, atau tetikus.


  • Gravitasi juga dapat ditampilkan di tampilan Play.
    Untuk game bergaya pinbal atau Mario, aktifkan Dynamics (fisika).
    Tambahkan node Setting dan aktifkan Dynamics di Property-nya agar fisika berlaku untuk seluruh program.
    Setiap node objek juga punya pengaturan Dynamics sendiri, jadi masing-masing perlu diaktifkan.

3. Tiga tampilan

3-1. Menggunakan NodeEditor

Di sinilah Anda menata node dan menyambungkannya dengan kabel.


Tindakan Hasil

Cubit dua jari, roda tetikus Memperbesar/memperkecil tampilan
Klik ganda lalu seret (latar belakang) Memilih dengan kotak (memilih beberapa node)

Menyeret keluar dari konektor lalu melepasnya juga memutus sambungan

3-2. Menggunakan tampilan Layout

Di sinilah Anda menentukan posisi, ukuran, dan rotasi objek. Persegi panjang abu-abu adalah area yang terlihat saat Play.


Cara pengoperasiannya pada dasarnya sama dengan NodeEditor.

Tindakan Hasil
Seret satu jari (latar belakang) Menggeser tampilan
Roda tetikus / cubit dua jari Memperbesar/memperkecil
Seret objek Memindahkan (jika beberapa terpilih, semuanya sekaligus)
Ketuk objek Memilih. Pilihan ini juga berlaku di NodeEditor
Seret pegangan Mengubah ukuran / memutar
Klik ganda lalu seret (latar belakang) Memilih dengan kotak
Tekan lama latar belakang Membuka CREATE NODE
Tekan lama pilihan Membuka Property (jika beberapa objek terpilih, menu Duplicate/Delete)
Saat sebuah objek terpilih, muncul angka seperti “50” di sebelah kanannya.
Angka itu adalah SortingLayer: makin besar angkanya makin depan objek digambar, makin kecil makin belakang.
Anda dapat mengubahnya dengan tombol ▲▼ di bawahnya.

Selain itu, node SETTING menyediakan pilihan GridSnap.
Jika aktif, objek bergerak dalam satuan 10 piksel.

Ukuran area abu-abu diatur di node Setting.

4. MENU

Tekan lama tombol MENU di kanan atas, geser jari ke arah salah satu pilihan, lalu lepaskan untuk menjalankannya. Tombol ini juga bisa dipakai seperti tombol biasa.

Tombol ▶ di kanan atas berpindah ke Play dan menjalankan program.
Layout  membawa Anda ke tampilan Layout.

4-1. Pilihan pada menu

NEW NODE Membuka CREATE NODE untuk menambahkan node baru. Menekan lama latar belakang juga membuka hal yang sama.
SAVE Menyimpan program saat ini dengan sebuah nama (lihat 4-2).
LOAD Memuat program yang tersimpan (lihat 4-3).
UNDO Membatalkan tindakan terakhir.
REDO Mengulangi tindakan yang dibatalkan.
FIT Mengatur perbesaran dan posisi agar seluruh node muat di layar.
NEW Menghapus semuanya dan memulai program baru.
SETTING Membuka pengaturan aplikasinya sendiri (lihat 4-4). Ini berbeda dengan node SETTING.
OPEN HELP Membuka halaman bantuan ini.

Saat Anda sedang menyunting di dalam sebuah Compo, pilihan di kolom kiri berganti menjadi pilihan khusus Compo. Semuanya dijelaskan di bab “Node Compo”.

4-2. SAVE (menyimpan)

Menyimpan program dengan sebuah nama di perangkat ini. Nama yang sudah ada akan ditimpa. Nama boleh memakai huruf Latin, angka, dan beberapa simbol.
AUTO akan menyalakan penyimpanan otomatis: setelah itu program disimpan setiap 30 detik (tidak pernah saat Play).
EXPORT menulis program ke sebuah berkas — berguna untuk cadangan atau untuk dibagikan.
Anda bisa memilih format .ngz (terkompresi gzip) atau .json (teks).
Cukup ubah ekstensi berkas .ngz menjadi .gz, lalu perangkat lunak pengekstrak biasa pun bisa mengeluarkan JSON-nya.

Anda dapat menyimpan hingga 256 program. Semuanya tersimpan di dalam peramban yang Anda pakai, jadi tidak terlihat dari perangkat atau peramban lain.
Data simpanan itu berada di dalam nodegram, jadi menghapus pintasan nodegram dari ponsel bisa ikut menghapus datanya.
Untuk hal yang penting, sebaiknya gunakan EXPORT dan simpan sebagai berkas.

4-3. LOAD (memuat)

Menampilkan daftar program yang tersimpan. Tombol di samping tiap nama juga dapat menghapusnya.
IMPORT memuat berkas yang sebelumnya diekspor. Ada dua cara memuat: memuat menggantikan isi yang sekarang, sedangkan menambahkan mempertahankan program yang berjalan dan menyisipkan berkas itu di bawahnya.

Jika Anda mengimpor berkas .obj yang dibuat di perangkat lunak 3D, data 3D-nya akan dimuat sebagai node POLYGON, atau sebagai node ARRAY yang menempel pada node LINE (tampilan 3D). Selengkapnya lihat 9-11. Objek 3D.

4-4. SETTING (pengaturan aplikasi)

Pengaturan aplikasinya sendiri. Yang diubah di sini tidak ikut tersimpan dalam program, melainkan hanya berlaku di perangkat ini.
Wire: memilih bentuk kabel (melengkung atau lurus).
NodeColor: memilih skema warna node.
Language: mengubah bahasa tampilan.
Jepang, Inggris, Tionghoa (Sederhana), Prancis, Jerman, Hindi, Indonesia, Italia, Korea, Portugis, Rusia, Spanyol, Thai, Turki, dan Vietnam

Pengaturan per adegan seperti FPS atau Dynamics tidak ada di sini, melainkan di node SETTING. Namanya mirip, jadi jangan sampai tertukar.

5. Di ponsel dan PC


Di ponsel
  • Kendali sentuh:
    Geser dengan satu jari, cubit dengan dua jari untuk memperbesar. Tekan lama, ketuk ganda lalu seret, dan lainnya bekerja sama seperti di PC.

  • Memutar layar:
    Tampilan mengikuti arah perangkat. Saat Play, arah yang dipakai adalah yang ditetapkan di node SETTING (Horizontal atau Vertical); jika perangkat dipegang terbalik, akan muncul pemberitahuan.
  • Catatan untuk iOS: 
    Di perangkat iOS seperti iPhone, buka menu Safari lalu ketuk ① dan ② untuk menyembunyikan bilah alat. Hasilnya mendekati layar penuh dan membuat nodegram jauh lebih nyaman dipakai.
    Untuk layar penuh sesungguhnya, buka menu berbagi Safari dan pilih “Tambahkan ke Layar Utama”. nodegram lalu berlaku seperti sebuah aplikasi — inilah yang kami sarankan.
    Perhatikan bahwa menghapus ikon itu dari Layar Utama bisa ikut menghapus data simpanan Anda. Ekspor hal-hal penting ke sebuah folder di perangkat Anda.

6. Referensi node



In/Out berarti jumlah konektor masukan / jumlah konektor keluaran.

Konstanta

Node Masukan/Keluaran Keterangan
Constant 0/1 Mengeluarkan angka yang ditetapkan pada Value.

Perhitungan

Node In/Out Keterangan
＋ 2/1 Mengeluarkan hasil masukan 1 ＋ masukan 2.
Node penjumlah tidak selalu diperlukan: setiap konektor masukan dapat menerima beberapa kabel sekaligus dan menjumlahkannya, jadi dua kabel pada masukan 1 sudah menghasilkan jumlahnya.
－ 2/1 Mengeluarkan hasil masukan 1 － masukan 2
× 2/1 Mengeluarkan hasil masukan 1 × masukan 2
÷ 2/1 Mengeluarkan hasil masukan 1 ÷ masukan 2. Jika penyebutnya 0, keluarannya 0.
√ 1/1 Mengeluarkan akar kuadrat dari masukan 1. Jika masukannya 0 atau kurang, keluarannya 0.
Compare 2/1 Membandingkan masukan 1 dengan masukan 2 (=, >, <, ≠, ≥, ≤). Mengeluarkan 1 bila syaratnya terpenuhi, dan 0 bila tidak.
Not ( ! ) 1/1 Mengeluarkan 1 bila masukan 1 sama dengan 0, dan 0 bila tidak.
Pos Angle 2/1 Posisi ke sudut. Mengeluarkan ArcTan2(masukan 2, masukan 1) dalam derajat.
Angle Pos 1/2 Sudut ke posisi. Mengeluarkan (cos, sin) untuk sudut dalam derajat.
Random 1/1 Mengeluarkan bilangan bulat acak dari 0 hingga kurang dari Number. Nilai baru diambil saat Play dimulai dan pada setiap frame ketika masukan 1 bukan nol. Jika Use Seed diaktifkan dan sebuah nilai Seed diberikan, urutan yang sama terulang setiap kali Play.
Int 1/1 Membulatkan menjadi bilangan bulat. Property Round menyediakan Floor, Round, dan Integer.
Floor (bawaan) mengambil bilangan bulat terbesar yang tidak melebihi masukan: 2,8 menjadi 2 dan -0,1 menjadi -1. Round membulatkan ke yang terdekat, sedangkan Integer hanya menyisakan bagian bulatnya.

Nilai dan waktu

Node In/Out Keterangan
Trigger 1/1 Mengeluarkan 1 selama tepat satu frame ketika masukannya berubah dari 0 menjadi nilai lain.
DELAY(F) menunda angka 1 itu sebanyak frame yang ditentukan.
Counter 2/1 Sebuah pencacah. Setiap frame ia menambahkan masukan 1, mengurangi masukan 2, lalu mengeluarkan nilai yang disimpannya.
Type＝Clamp menahannya di antara Min dan Max, sedangkan Loop membuatnya berputar dalam rentang itu. Value (nilai awal), Min, dan Max dapat diatur.
Var 2/1 Berfungsi sebagai variabel: menyimpan satu angka lalu mengeluarkannya.
Ketika sinyal set pada masukan 2 bukan nol, ia mengingat masukan 1.
Nilai awalnya dapat ditentukan.
Array 3/1 Berfungsi sebagai larik (array).
Berikan indeks pada masukan 2 (posisi dalam larik, dimulai dari 0), dan node ini mengeluarkan elemen tersebut. Karena penomoran mulai dari 0, larik berukuran 3 memakai 0, 1, atau 2; di bawah 0 dan mulai dari 3 keluarannya 0.
Sinyal set pada masukan 3 menimpa elemen pada indeks (masukan 2) dengan nilai masukan 1.
Pisahkan nilai-nilai awal dengan koma atau pergantian baris.
Larik dapat dipakai sebagai partitur bagi node Sound dan sebagai garis patah bagi node Line. Tombol SEQUENCER dan LINE pada Property membuka editor khusus untuk kedua keperluan itu (lihat di bawah).
Larik juga menyimpan rangka kawat 3D (lihat 9-11. Objek 3D).
GetPos 0/2 Membaca posisi X dan Y objek induk saat ini. Dapat dialihkan antara WORLD dan LOCAL.
GetRot 0/1 Mengeluarkan sudut objek induk saat ini, dengan arah berlawanan jarum jam sebagai positif. Dapat dialihkan antara WORLD dan LOCAL.
Velocity 0/2 Mengeluarkan kecepatan X dan Y objek induk per detik (Y positif ke atas). Nilai Frames yang lebih besar merata-ratakan lebih banyak frame sehingga perubahannya tampak lebih halus.

Editor khusus ARRAY (SEQUENCER / LINE)


  • Editor LINE：
    Alat untuk menggambar garis patah yang akan diberikan kepada node Line.
    Titik asalnya ada di tengah area gambar; X positif ke kanan dan Y positif ke atas, keduanya dari -99 hingga 99.
    DRAW menggambar garis. Saat menggambar, tombol DRAW berubah menjadi Endpoint; menekannya akan menuntaskan garis yang sedang dibuat.
    MOVE memindahkan titik, ERASE menghapus satu ruas, VIEW menggeser tampilan, dan ◁ ▷ untuk Undo/Redo. Saat ditutup, gambar itu menjadi daftar angka x,y, dengan x,y = (9999,9999) sebagai pemutus garis.
    Tetapkan node LINE sebagai induk node ARRAY, maka node LINE itu akan menggambar isi lariknya. Satu node ARRAY juga boleh punya beberapa induk (beberapa node LINE).


  • Editor SEQUENCER：
    Alat untuk menyusun larik partitur bagi node Sound. Hanya not seperdelapan, 8 per birama, hingga 500 birama, 3 oktaf.
    Pada mode DRAW, klik atau seret untuk meletakkan not; pada mode ERASE, seret untuk menghapusnya.
    Saat ditutup, Anda mendapat larik not seperdelapan dengan do＝0 dan re＝1. Tanda istirahat adalah 99 (sebenarnya setiap nilai di atas 80 dianggap istirahat), dan birama yang memuat not terakhir diisi tanda istirahat sampai penuh. Nada setengah ditulis sebagai 0,5.
    Jika Chromatic dicentang, setiap kotak menjadi salah satu dari 12 nada setengah (do=0, do♯=1, re=2, re♯=3, mi=4, fa=5, fa♯=6, sol=7, sol♯=8, la=9, la♯=10, si=11), sehingga satu oktaf berisi 12. Node Sound punya kotak centang yang sama — samakan keduanya.


  • Larik saja tidak mengeluarkan bunyi; diperlukan program seperti pada tautan di bawah.

    ▶ Buka contoh

Anda juga dapat menyunting beberapa rangkaian (ARRAY) sekaligus.
Pilih beberapa node ARRAY di NodeEditor, tekan lama salah satunya,
lalu pilih “SEQUENCER”.
Tombol bernomor memilih larik yang disunting, menekannya lama membuka menu volume,
dan Anda bisa menyeretnya untuk mengubah urutan.



Keluaran dan objek

Node In/Out Keterangan
Text 2/0 Menampilkan teks. Jika tidak ada yang tersambung, teks pada Property Text yang ditampilkan; jika ada kabel, nilai itulah yang tampil. Masukan 2 menyalakan dan mematikan tampilan. Angka dibulatkan pada desimal keenam dan ditampilkan sampai desimal kelima. Warna teks, tata letak, dan bingkai di sekelilingnya dapat diatur.
Rect 3/0 Objek persegi panjang. Bila Dynamics mati, masukan 1 dan 2 adalah koordinat x/y; bila menyala, keduanya menjadi gaya luar. Masukan 3 menyalakan dan mematikan tampilannya. Warna, garis tepi, Tag, ukuran, rotasi, Sorting Layer, dan lainnya dapat diatur. Broken by 1–3 menyebutkan My Tag dari objek yang dapat menghancurkannya.
Untuk Dynamics dan Tag, lihat 9. Spesifikasi.
Circle 3/0 Objek lingkaran. Selain bentuk dan Property Radius, masukan dan Property-nya sama dengan RECT.
Character 3/0 Karakter yang bisa berjalan dan melompat. Masukan 1 dan 2 adalah kecepatannya; masukan 3 memicu lompatan tepat pada saat ia berubah dari 0 atau kurang menjadi nilai positif.
Tinggi lompatan sebanding dengan nilai masukan dan hanya berlaku saat menyentuh tanah. Agar fisika dan lompatannya bekerja, aktifkan Dynamics baik di SETTING maupun di Character. Untuk game tampak-atas, biarkan Dynamics menyala lalu setel Gravity ke 0. Flip membalik tekstur sesuai arah hadap, AutoRot memutar karakter ke arah geraknya, dan KeepOnScr menahannya di dalam layar.
Ia memang punya konektor anak, tetapi tidak bisa menjadi anak dari sebuah objek. Satu-satunya yang bisa menjadi induknya adalah WARP IN.
Shot 1/1 Masukan 1 menembakkan peluru. Bullet Count adalah jumlah peluru yang bisa ada bersamaan. My Tag menghancurkan apa pun yang Broken by-nya cocok, sedangkan Broken by 1–3 pada node SHOT menentukan apa yang memusnahkan pelurunya — berdasarkan jenis node atau Tag. Keluarannya bernilai 1 hanya pada frame ketika tembakan benar-benar terjadi. Keep Off-Screen mempertahankan peluru di luar layar, dan bila batasnya terlampaui, peluru terlama akan hilang.
Line 5/0 Menggambar garis dari (X1,Y1) ke (X2,Y2). Bila masukan 5 (SET) tersambung, bentuknya diperbarui selama masukan itu bukan nol, dan bentuk sebelumnya dipertahankan saat bernilai 0. Bila tidak tersambung, bentuknya diperbarui setiap frame.
Bila sebuah ARRAY dijadikan anak, masukan 1–4 diabaikan: larik dibaca sebagai x1,y1,x2,y2,… dan digambar sebagai satu garis patah yang menyambung. x=9999, y=9999 memutus garis. Coord dapat dialihkan antara WORLD dan LOCAL.
Bila ARRAY anaknya berisi data 3D (tiga angka x,y,z), ia otomatis digambar sebagai 3D LINE. Selengkapnya lihat 9-11. Objek 3D.
Sound 3/0 Masukan 1 adalah nada (do=0, re=1, …), masukan 2 volume, dan masukan 3 sinyal bunyi. Bila masukan 1 dan 2 tidak tersambung, Property Tone dan Volume yang dipakai. Bunyi bertahan berbunyi selama sinyalnya bukan nol, sedangkan bunyi meluruh dan efek berbunyi sekali pada tepi naik atau saat nadanya berubah. Nada di atas 80 (misalnya 99) berarti istirahat. Property Tone bergerak dalam satuan 0,5 (satu nada setengah), sedangkan masukan 1 menerima nilai desimal apa pun.
Bila Chromatic aktif, Tone menjadi bilangan nada setengah dari 12 (0=do, 1=do#, 2=re…). Bila mati, Anda mendapat tangga nada 7 tingkat dengan 0,5 sebagai tuts hitam. Bila memasukkan larik sebagai nada, samakan pengaturan ini dengan Chromatic pada SEQUENCER larik itu, jika tidak nadanya akan meleset.
Polygon 7/0 Objek yang menampilkan bidang (poligon) sebuah model 3D. Ia tidak dapat dibuat lewat CREATE NEW NODE; ia hanya terbentuk saat berkas .obj diimpor.
Masukannya adalah posisi 3D, rotasi 3D, dan skala.
Selengkapnya lihat 9-11. Objek 3D.

Kendali

Node In/Out Keterangan
Stick 1/2 Joystick di layar. Kemiringan mendatar tuasnya adalah keluaran 1, dan yang tegak keluaran 2. Bisa analog atau digital, dan dapat dipetakan ke papan ketik atau gamepad.
Button 1/1 Tombol di layar. Mengeluarkan 1 selama ditekan. Dapat dipetakan ke papan ketik atau gamepad.
Keyboard 0/1 Mengeluarkan 1 selama tombol yang ditetapkan ditekan.
Touch 0/3 Sentuhan layar. X titik sentuh adalah keluaran 1 dan Y-nya keluaran 2 (pusatnya 0,0); keluaran 3 bernilai 1 selama layar disentuh.

Node lainnya

Node In/Out Keterangan
TEXTURE 1/0 Menyimpan gambar piksel yang Anda buat lalu menempelkannya pada objek yang dijadikan induk. Dapat dipasang pada Rect, Circle, Chara, Shot, dan BG, serta boleh punya beberapa induk (beberapa node objek).
Masukan bernilai 0 menyembunyikannya. Dengan menyambungkan beberapa tekstur ke satu objek dan hanya menyalakan Visible pada salah satunya, Anda dapat berganti-ganti tekstur.
Anda dapat memilih apakah gambarnya dipaskan ke objek atau dijejerkan seperti ubin.
Tanpa induk, tekstur juga dapat ditampilkan sendiri sebagai gambar datar.
Bila satu gambar dibutuhkan di banyak tempat — misalnya untuk latar — satu tekstur dapat diberikan ke beberapa objek.
Untuk editor teksturnya sendiri, lihat “editor TEXTURE”.
SENSOR 0/1 Mengeluarkan jumlah objek yang bersinggungan dengan area sensor (rentang yang ditetapkan di tampilan Layout). Sebuah objek terhitung bila memenuhi syarat Target atau salah satu dari Tag 1–3, dan setiap objek hanya dihitung satu kali sekalipun memenuhi beberapa syarat sekaligus. Bila Target=SCREEN, keluarannya 0 atau 1 tergantung apakah area sensor bersinggungan dengan layar yang terlihat. Bila punya induk, sensor ikut bergerak bersamanya, dan induk itu sendiri dikecualikan dari pendeteksian.
ONBREAK 1/1 Mengeluarkan berapa banyak objek induk atau objek ber-Tag tertentu yang hancur pada frame ini. Objek induknya boleh lebih dari satu.
Tanpa sesuatu untuk diawasi pun, node Onbreak tetap dapat dipakai sebagai node efek: ia juga memunculkan efek di posisinya sendiri ketika masukan 1 berubah dari 0 menjadi nilai lain. Jenis efek (NONE, PARTICLE, LINE, CIRCLE, BOX) dan warnanya dapat diatur.
ROTATE 1/0 Engsel untuk memutar sekelompok objek induk-anak. Objek yang menjadikan ROTATE sebagai induk akan mengikuti posisi dan rotasinya. Masukan 1 adalah selisih rotasi terhadap sudut awal yang ditetapkan di Layout, dan nilai positif memutar berlawanan jarum jam.
SCREEN 3/2 Mengendalikan kamera saat Play. X/Y adalah posisi kamera (bila ada induk, selisih terhadap induk itu; Y positif ke atas) dan S adalah perbesarannya, minimum 0,05. Objek yang menjadikan SCREEN sebagai induk berubah menjadi HUD tetap yang tidak terpengaruh kamera.
Jadikan objek pemain sebagai induk SCREEN, maka tampilan akan mengikuti pemain.
RESTART 1/1 Bila masukannya berubah dari 0 menjadi nilai lain, seluruh program kembali ke keadaan saat Play dimulai. Posisi, variabel, pencacah, larik, peluru, dan lainnya diatur ulang. Nilai yang memicu pengulangan itu tetap tersimpan di keluarannya, sehingga berguna untuk meneruskan sisa nyawa atau skor.
COMPO 3/3 Sebuah komponen yang membungkus beberapa node menjadi satu. E＝menyalakan/mematikan, 1 dan 2＝bertukar nilai dengan bagian dalamnya.
Selengkapnya lihat 7. Node Compo.
  • Editor TEXTURE：
    Dibuka lewat tombol “Edit Texture” pada Property node TEXTURE. Di sini Anda menggambar gambar piksel yang kemudian ditempelkan pada objek yang dijadikan induk.
    DrawMenggambar titik dengan warna yang dipilih. Menyeretnya menggambar terus-menerus.
    PaintMengisi sekaligus area berwarna sama yang menyambung.
    PickMengambil warna dari gambar dan menjadikannya warna aktif.
    ViewMemperbesar dan menggeser tampilan.
    Copy / PasteMenyalin area terpilih lalu menempelkannya di tempat lain.
    ◁ / ▷UNDO / REDO

    Pilih warna dari palet di bawah. Untuk menghapus, pilih warna transparan lalu gambar dengannya.
    Jumlah titiknya diatur lewat Property Size. Ukuran hingga 256*256 memungkinkan, tetapi jumlah langkah Undo berkurang dan editornya melambat. Untuk objek SHOT, buat teksturnya sekecil mungkin.
    Setelah selesai, tutup editor dengan × di kanan atas.
    Tekan lama sebuah kotak palet untuk memilih warna apa pun.

    Di PC, gambar yang disalin dari perangkat lunak lain dapat langsung ditempelkan ke dalam editor. Tergantung aplikasi dan perangkatnya, ini juga bisa dilakukan di ponsel.

Warp

Node In/Out Keterangan
WARP IN 1/0 “Pintu masuk” untuk memindahkan sebuah objek. Ia bekerja pada objek yang dijadikan anaknya. Begitu masukannya bukan nol, anak itu melompat ke posisi dan sudut WARP OUT dengan Index yang sama, lalu tetap di sana selama masukannya belum nol; begitu kembali ke 0, ia dilepaskan dan bebas bergerak lagi. Property-nya hanya Index. Tidak dapat ditempatkan di dalam Compo.
WARP OUT 0/0 “Pintu keluar” warp. Objek yang dikirim oleh WARP IN dengan Index yang sama akan muncul pada posisi dan sudut ini. Property-nya hanya Index. Di tampilan Layout ia dapat dipindahkan dan diputar (ia tidak punya ukuran, jadi tidak dapat diskalakan). Dengan objek sebagai induknya, ia ikut bergerak. Tidak dapat ditempatkan di dalam Compo.

Sinyal

Node In/Out Keterangan
IN 1/0 Mengirim sebuah nilai ke tempat yang jauh dalam program. Apa pun yang Anda sambungkan ke node IN akan keluar dari setiap node OUT dengan indeks yang sama. Dua node IN dengan indeks sama tidak diperbolehkan. Dengan indeks Compo, ia juga dapat menjangkau bagian dalam Compo itu.
Untuk node Compo, lihat 7. Node Compo.
OUT 0/1 Menerima nilai yang dikirim dari tempat lain. Apa yang masuk ke node IN akan keluar di sini, pada setiap node OUT dengan indeks itu — beberapa node OUT dengan indeks sama diperbolehkan. Dengan indeks Compo, ia juga dapat menjangkau bagian dalam Compo itu.
Untuk node Compo, lihat 7. Node Compo.

Pengaturan adegan

Node In/Out Keterangan
MEMO 0/0 Catatan yang Anda tulis di bidang kerja. Ia tidak digambar saat Play.
BG 0/0 Latar belakang layar Play. Satu untuk tiap adegan, dan selalu berada paling belakang.
Bila Anda memberinya node TEXTURE, gambar itu dijejerkan seperti ubin menutupi latar. Tanpa tekstur, Color mengisi latar dengan satu warna.
SETTING 0/0 Pengaturan untuk seluruh adegan.
Arah layar ponsel (ScreenOrient), ukuran area Play (ScreenSize, ScreenLong, ScreenShort), FPS, Dynamics (Gravity, Friction%, Bounce%, Drag%), warna tombol henti (StopBtnCol), dan GridSnap. Hanya satu per adegan.
Bila adegan memuat node yang berkaitan dengan 3D, muncul pula Property untuk tinggi titik pandang dan jaraknya ke layar.

7. Node Compo

  • Sebuah node khusus yang memungkinkan sekelompok node diperlakukan sebagai satu node.

    Bayangkan kombinasi node yang sama muncul sepuluh kali dalam program Anda — tentu Anda ingin membuatnya sekali lalu memakainya berulang.
    Di nodegram, Anda membungkus beberapa node menjadi satu node Compo lalu menggandakan Compo itu.

    Untuk sepuluh musuh yang sama, buatlah satu dulu, bungkus node-nya menjadi sebuah Compo, gandakan Compo itu, lalu tempatkan salinannya di Layout.

    Node Compo hasil penggandaan memakai program yang sama persis: mengubah salah satunya mengubah yang lain juga. Namun tiap salinan tetap punya koordinat, variabel, masa hidup, dan sebagainya sendiri-sendiri saat program berjalan.

  • Langkah membuat node Compo
  1. Pilih node-node yang ingin Anda bungkus.
    Untuk memilih beberapa sekaligus, klik ganda lalu seret.
    Pada klik kedua, jangan lepaskan tetikus; seretlah untuk membuat kotak pilihan.
    Di ponsel rasanya seperti “ketuk, ketuk-tahan, geser”.
    (Pada contoh ini pesawat pemain ada di kiri, dan bagian yang dikotaki adalah program satu pesawat musuh yang mendekat.)



  2. Dengan beberapa node terpilih, tekan lama salah satunya untuk membuka menu. Pilih “MAKE COMPO” lalu jawab “Yes” pada konfirmasinya.




  3. Node-node itu kini menjadi satu node Compo bernama “C1”.


  4. Tekan lama C1 (atau klik ganda) untuk masuk dan menyunting isi Compo di NodeEditor tersendiri.
    Kabel yang tadinya masuk ke Compo kini tampak sebagai node OUT bernama “C1 1” dan “C1 2”.

    Tekan “MENU” di kanan: kolom kiri kini berisi perintah-perintah Compo.
    “Duplicate” membuat salinan node Compo ini.
    Tombol “PARENT” di kanan bawah meninggalkan NodeEditor ini dan kembali ke NodeEditor di atasnya.



  5. Di NodeEditor induk Anda dapat melihat bahwa kini ada beberapa node Compo.
    “C1 (2)” juga perlu menerima masukan yang sama, jadi sambungkan masukan dan keluarannya seperti itu pula.



  6. Tekan “LAYOUT” lalu tempatkan tiap Compo di tempat yang Anda inginkan.


  7. Tekan Play “▶”: ada beberapa pesawat musuh, dan masing-masing bergerak sendiri.

  8. Untuk membuat banyak salinan sekaligus, pilih node-node Compo bersamaan, tekan lama salah satunya, lalu pilih “Duplicate”.
    Dan bila semua Compo perlu menerima nilai yang sama, node IN dan OUT sangat memudahkan.


  • Node Compo dan instans

    Bila dua node Compo berisi hal yang sama sehingga mengubah salah satunya ikut mengubah yang lain, keduanya disebut “berhubungan sebagai instans”; menggandakan sebuah Compo berarti “membuat instans dari node Compo itu”.
    Node Compo dengan nomor Compo yang sama berhubungan sebagai instans dan berbagi satu program.
    (Memutus hubungan instans itu disebut Unique, dan ada di menu geser Compo. Lihat di bawah)

    Angka setelah huruf C menyatakan Compo yang mana: angka sama berarti instans dari Compo yang sama.
    “C1 (1)” dan “C1 (2)” berhubungan sebagai instans.
    “C1 (1)” dan “C2 (1)” adalah Compo berbeda dan tidak berhubungan.
    Angka di dalam tanda kurung hanya membedakan salinan-salinan dari satu Compo.

    Sekalipun Compo saling berhubungan sebagai instans, setiap parameter diperlakukan terpisah saat Play.
    Kemunculan dan hilangnya karakter, koordinatnya, serta node count, var, dan array di dalamnya semuanya menyimpan nilai masing-masing.

  • MENU di dalam node Compo


    Duplicate dan Delete：menggandakan atau menghapus node Compo.

    Unique    ：memutus hubungan instans Compo ini. Berguna bila Anda ingin mengubah salinan sebuah Compo menjadi musuh yang lain. Nomor Compo-nya berganti menjadi nomor baru.

    Expand    ：mengembalikan node dari Compo yang sedang disunting ke NodeEditor utama, dan Compo itu sendiri lenyap. Ini kebalikan dari Make Compo. Compo yang merupakan instansnya tidak ikut di-Expand.

  • Node Compo bersama node IN dan OUT

    Node Compo hanya punya dua konektor masukan dan dua keluaran, tetapi node IN dan OUT dapat menambah jumlahnya.
    Property node IN dan OUT dapat memuat nomor Compo, sehingga sebuah nilai dapat dikirim ke Compo tertentu.


    Di dalam sebuah Compo, Anda boleh memakai node IN tanpa nomor Compo.
    Di dalam sebuah Compo, node OUT tanpa nomor Compo tidak boleh dipakai (karena dua node OUT yang sama tidak diperbolehkan).

    Perhatikan: node IN atau OUT bernomor Compo yang tampak persis sama akan berarti sangat berbeda tergantung ia berada di dalam atau di luar Compo.
    Pada gambar di atas, “node IN (biru): C1 indeks 2” muncul baik di dalam maupun di luar Compo, dan keduanya bukan hal yang sama. Yang di dalam menempel pada keluaran 2 Compo, sedangkan yang di luar menempel pada masukan 2 Compo dan meneruskan nilainya ke “node OUT: C1 indeks 2” di dalam.

  • Masukan dan keluaran Enable pada Compo

    Bila Anda memakai node Compo sebagai sebuah karakter, masukan dan keluaran Enable mengendalikan kapan karakter itu muncul dan lenyap.

    Keluaran Enable bernilai 1 selama karakter itu ada, dan menjadi 0 begitu ia hancur.

    Ketika masukan Enable berubah dari 0 menjadi 1 (atau nilai lain yang bukan nol), program di dalam Compo mulai berjalan dan karakternya menjadi aktif. Ia hanya bertahan selama masukan itu tetap bukan nol: bila kembali ke 0 atau karakternya hancur, ia pun lenyap.
    Bila tidak ada yang tersambung ke masukan Enable, keadaannya seolah-olah 1 diberikan terus-menerus.

    Bahkan karakter yang sudah lenyap akan mulai lagi dari keadaan awalnya begitu masukan itu berubah lagi dari 0 menjadi nilai lain.
    Di bawah ini adalah program yang memunculkan kembali karakter di posisi awalnya 3 detik setelah ia hancur.


  • Satu induk per node Compo

    Di dalam sebuah Compo, rantai induk-anak antarobjek tidak boleh memuat lebih dari satu node objek induk teratas. Dua karakter dalam satu node Compo belum terpikirkan.
    Dua induk tidak jadi masalah selama keduanya punya induk bersama di atasnya.
    Tidak ada node objek sama sekali (jadi tanpa induk) juga tidak masalah.


  • Node yang tidak dapat dibuat di dalam Compo

    BG, Setting, Stick, Button, Screen, dan OnBreak tidak dapat dibuat di dalam Compo.

9. Spesifikasi

9-1. Hanya 2D

nodegram sepenuhnya 2D. Ada dua sumbu: X (positif ke kanan) dan Y (positif ke atas). Aktifkan Dynamics di node Setting, dan karakter akan jatuh ke bawah layar.
Untuk game tampak-atas, matikan Dynamics di node SETTING, atau setel gravitasi keseluruhan ke 0.

9-2. FPS

Pilih laju frame sasaran di node SETTING: 60 atau 30 (bawaan 60). Baik perhitungan node maupun fisikanya berjalan pada laju itu. Bila programnya terlalu berat, Play melambat dan laju frame sebenarnya turun di bawah nilai yang ditetapkan.

9-3. Dynamics (perilaku fisika)

Objek seperti Rect, Circle, Character, dan Shot dapat diberi mode fisika (Dynamics). Perilakunya kurang lebih seperti Rigidbody2D pada Unity.

Mode Perilaku
Off Tanpa fisika. Masukan node (X,Y) langsung memindahkan koordinatnya.
Static Dinding atau lantai yang tak bergerak. Gravitasi dan tumbukan tidak menggesernya.
Dynamic Bergerak secara fisis karena gravitasi dan tumbukan. Masukan X/Y node bekerja sebagai gaya.
Kinematic Tidak digeser oleh gravitasi dan tumbukan, tetapi dapat digerakkan lewat masukan node; ia tetap bertumbukan dengan objek Dynamic dan dapat mendorongnya.

Tidak ada pengaturan kerapatan; semuanya diperlakukan kira-kira seperti kayu biasa.

9-4. SortingLayer (urutan tampil)

Nilai SortingLayer tiap objek (0–100, bawaan 50) menentukan urutan tumpukan di layar Play. Makin besar angkanya makin depan ia digambar. BG (latar belakang) selalu berada paling belakang.
Objek bernilai sama tampil sesuai urutan penambahannya.

9-5. Koordinat

  • X positif ke kanan dan Y positif ke atas. Pusat Layout adalah titik asal (0,0).
  • Sudut dinyatakan dalam derajat, dan arah berlawanan jarum jam bernilai positif. 0°＝kanan (X＋), 90°＝atas (Y＋), 180°＝kiri (X−), 270°＝bawah (Y−). ANGLE POS, POS ANGLE, GetRot, ROTATE, dan Property Angle sebuah objek semuanya mengikuti aturan ini.
  • Property Coord pada sebuah objek mengubah arti masukan X/Y node.
    • WORLD：masukan berlaku sebagai koordinat mutlak (relatif terhadap induknya bila ada).
    • LOCAL：masukan berlaku sebagai selisih dari penempatan awalnya. Bila ada induk, selisih terhadap induk itu ikut disertakan (koordinat Parent).
  • Untuk koordinat objek 3D, lihat 9-11. Objek 3D.

9-6. Resolusi

Area yang terlihat saat Play sama dengan persegi panjang abu-abu di Layout.
Arahnya (Horizontal atau Vertical) diatur di node SETTING — bukan di menu Setting — dan tampilannya menyesuaikan ukuran layar sebenarnya.
Bila Anda ingin resolusi tetap, gunakan ScreenSize pada node Setting.

9-7. Tag

Tag adalah sebuah kelompok.
Misalnya beri semua musuh kecil Tag “Enemy_tiny”, atau bedakan latar yang bisa dihancurkan dari yang tidak dengan “bg_destroyed” dan “bg”.
Node Shot, OnBreak, Rect, Circle, dan Character semuanya memakai Tag.


9-8. Bekerja dengan node


  • Satu konektor masukan dapat menerima beberapa kabel sekaligus, dan node itu menerima jumlahnya. Pada gambar, konektor teratas menerima 10+20→30.

  • Sambungan induk-anak antarnode (dari konektor atas ke konektor bawah) tidak hanya membuat objek bergerak bersama; ia juga menyatakan sebuah hubungan.
    Contohnya node Texture dengan node objek, node OnBreak dengan objek yang diawasinya, dan node Array dengan node Line.
    Biasanya satu induk boleh punya banyak anak, tetapi satu anak hanya boleh punya satu induk.
    Node Texture, OnBreak, dan Array adalah pengecualiannya: masing-masing boleh punya beberapa induk.


9-9. Apa yang terjadi dalam satu frame

Semua node diproses bersamaan.
Urutan pembuatan node tidak pernah mengubah hasilnya.

Node objek dan sejenisnya diproses sekali tiap frame.
Node yang mengingat nilai — Counter, Var, Trigger, Random, Array — juga hanya diperbarui sekali tiap frame.
Node hitung seperti ＋ dan × tidak mengingat apa pun, jadi ia dihitung saat nilainya dibutuhkan.
Sekalipun node hitung membentuk lingkaran, tiap node tetap hanya diproses sekali dalam satu frame.

9-10. UNDO / REDO

Dengan UNDO / REDO pada MENU, Anda dapat membatalkan atau mengulang pembuatan, penghapusan, pemindahan, penyambungan, perubahan Property, dan sebagainya. Anda dapat mundur hingga 50 langkah.

Editor TEXTURE, LINE, dan SEQUENCER masing-masing punya riwayat UNDO sendiri; gunakan tombol ◁ / ▷ di dalamnya. Editor LINE dan SEQUENCER juga mundur 50 langkah, sedangkan pada TEXTURE jumlahnya bergantung pada ukuran teksturnya.

Perhatikan bahwa menjalankan Play tidak dapat dibatalkan, begitu pula menyimpan dan memuat.

9-11. Objek 3D


nodegram punya dua cara menampilkan objek 3D: Polygon dan ARRAY + LINE (tampilan 3D). Keduanya hanya terbentuk saat berkas .obj diimpor (tidak dapat dibuat lewat CREATE NEW NODE).

Meski begitu, nodegram sendiri tetaplah panggung 2D. Objek 3D hanyalah cara memakai tampilan yang terkesan 3D sebagai bahan 2D, dan seperti objek 2D lainnya, urutan tampilnya ditentukan oleh pengaturan Sorting Layer-nya. Node Polygon dengan Sorting Layer yang sama diproses bersama sebagai satu adegan 3D, sehingga tumpang-tindih kedalamannya pun tampil dengan benar.

Objek 3D punya koordinat Z. Bidang layar adalah z=0, makin jauh ke dalam +z, dan ke arah penonton -z. Jarak titik pandang ke layar dan tinggi titik pandang dapat diatur di node setting.
Hubungan induk-anak dengan objek 2D tetap mungkin, tetapi sebaiknya kerjakan pada z=0.

Untuk menampilkannya sebagai LINE (tampilan 3D), isi ARRAY yang menjadi anak node LINE dengan rangkaian tiga angka x,y,z. Bagian sampai pemisah (9999,9999,9999) menjadi satu garis yang menyambung, dan yang setelahnya memulai garis baru (bentuknya: x,y,z, x,y,z, ,,, 9999,9999,9999, x,y,z, ,,,, 9999,9999,9999). Sebuah ARRAY juga boleh punya beberapa node LINE sebagai induk.

10. Hal yang perlu diperhatikan

  • Saat memakainya di ponsel：
    Menambahkan pintasan nodegram ke Layar Utama membuatnya terasa seperti aplikasi. Namun sama seperti aplikasi, menghapusnya (menghapus pintasan di Layar Utama) sangat mungkin ikut menghapus data simpanan Anda. Simpan program yang sudah jadi sebagai berkas terpisah lewat Export.

    Pada sebagian peramban ponsel, tampilan atau titik sentuhnya bisa bergeser.
    Bila itu terjadi, tutup nodegram, hapus tugasnya (ini berbeda dengan menghapus aplikasinya), pegang perangkat mendatar dengan rapi, lalu jalankan lagi — biasanya akan pulih.
  • Penyimpanan otomatis:
    Selama “auto save” aktif di layar simpan, berkas terakhir akan ditimpa setiap 1 menit. Bila ingin menyimpan terpisah, pakailah Save dengan nama baru.

  • Hak: 
    Segala yang Anda buat dengan nodegram sepenuhnya milik Anda. Kami tidak akan memakainya seenaknya dan tidak akan mengklaim hak apa pun atasnya.
    Kode dan spesifikasi nodegram sendiri adalah hak saya (harada). Mohon jangan menyebarkan ulang kode nodegram tanpa izin.

  • Hak cipta dan masalah: 
    Mohon jangan memakai materi berhak cipta tanpa berpikir panjang.
    Kami juga tidak dapat bertanggung jawab atas masalah yang timbul dari penggunaan nodegram (tentu kami tidak akan pernah sengaja menyisipkan kode yang menimbulkan masalah).
