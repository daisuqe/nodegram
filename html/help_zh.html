1. nodegram 是什么

nodegram 是用节点来编程的工具。

只要把摇杆节点和角色节点连起来，角色就能动起来。



• 在手机或电脑上都能编程。

• 可以让别人玩你做的游戏。
• nodegram 在网上运行，只要能联网，随时随地都能编程（一个 nodegram 程序的大小大约只相当于一张图片）。

什么是节点编程（Node Programming）
nodegram 提供了 40 多种节点：只做加法的节点、记住数字的节点、检查按键是否被按下的节点等等。
节点编程就是让许多“负责人”（Node）互相传递信息，一起完成一件大事。每个负责人都会接过前一个人交来的数值，做完自己那一份工作，再交给下一个人。所有负责人始终都在工作。
相比之下，一般的文字编程是由一个负责人按顺序理解并执行指令。

2. 基本用法


射击游戏的制作方法（2 分钟）

nodegram 有三个操作画面：
编写程序的 NodeEditor
摆放对象的 Layout 画面
运行程序的 Play 画面 

。

2-1. 创建节点（NodeEditor）

  • 在 NodeEditor 画面中长按背景（什么都没有的黑色区域），就会打开“CREATE NEW NODE”对话框。


  • 从节点列表中选择想要添加的节点，NodeEditor 中就会生成该节点。
  • 长按或双击已创建的节点，会打开用于设置该节点细节的属性（Property）对话框。
    对象的颜色等各项设置都在这里更改。
    这里没有“OK”按钮，数值一经修改立即生效。请按右上角的 × 或点击对话框外部来关闭它。
    DUPLICATE 用于复制节点，DELETE 用于删除节点。
  • 拖动节点（触摸并移动）即可移动节点。
  • 从节点右侧的输出端口拖到（其他节点左侧的）输入端口，即可连接连线。连好之后，程序运行时数值就会从红色端子传递到蓝色端子。



  • 顶部带有端子（子端子）的节点，从子端子连到（其他节点下方的）父端子后就形成父子关系，父对象移动时子对象也会跟着移动。
    例如玩家发射子弹的结构，就把发射口设为子、把玩家设为父。

2-2. 在画面中摆放对象（Layout 画面）

  • 按“Layout”按钮即可切换到 Layout 画面。


  • 在 Layout 画面中摆放 Rect、Circle、Character、Text 等对象类节点
    ，以及 Button、Stick 等操作类节点。


  • 拖动对象可移动位置，用对象四角的白色手柄调整大小，用上方的圆形手柄调整方向。
  • 按“NODE”按钮可返回 NodeEditor。

2-3. 运行程序（Play 画面）

  • 按 NodeEditor 或 Layout 画面右上角的▶（Play）按钮，即可切换到 Play 画面并运行程序。
  • 长按 Play 画面右上角的 □（Stop）按钮即可停止 Play 并返回编辑画面。
  • 在 Play 画面中，对象节点每 1/60 秒（1 帧）绘制一次，并随物理运算一起运动。
  • 可以通过触摸屏幕、JoyStick、键盘、鼠标等方式进行操作。


  • 在 Play 画面中也可以表现重力。
    制作弹球或马里奥这类游戏时，请打开 Dynamics（物理运算）。
    添加 Setting 节点并在 Property 中打开 Dynamics，整个程序的 Dynamics 处理就会生效。
    各个对象类节点也都有各自的 Dynamics 设置项，需要单独打开。

3. 三个视图的说明与操作

3-1. NodeEditor 的操作

这是排列节点并用连线连接的节点搭建画面。


操作 内容
单指拖动背景 移动视图
双指捏合、鼠标滚轮 放大 / 缩小视图
双击后拖动（背景） 框选（选中多个节点）
长按背景 打开 CREATE NEW NODE 画面
拖动节点 移动节点（选中多个时一起移动）
双击 / 长按节点 打开属性画面（选中多个时为多节点处理菜单）
在端子之间拖动 连接连线（为防止误操作，点按后需稍作停顿再拖动）
长按连线 / 向外拖出 断开连接
从端子向外拖动并松开也可以断开

3-2. Layout 画面的操作

这是决定对象位置、大小和旋转的画面。灰色矩形表示 Play 时的显示区域。


基本上与 NodeEditor 的操作相同。

操作 内容
单指拖动（背景） 移动视图
鼠标滚轮 / 双指捏合 放大 / 缩小
拖动对象 移动（选中多个时一起移动）
点击对象 选中。该选中状态与 NodeEditor 共享
拖动手柄 改变大小 / 旋转
双击后拖动（背景） 框选（多选）
长按背景 打开 CREATE NODE 画面
长按选中项 打开属性画面（选中多个时为 Duplicate/Delete 菜单）
选中对象后，右侧会出现“50”之类的数字。
这个数字是 SortingLayer 值，数值越大显示得越靠前，越小则越靠后。
用下方的 ▲▼ 按钮可以增减。

另外，在 SETTING 节点中可以设置 GridSnap。
打开后，对象将以 10 像素为单位移动。

灰色画面的大小可以在 Setting 节点中更改。

4. MENU

按住画面右上角的MENU按钮，把手指朝目标项目的方向滑动后松开，即可执行该项目。也可以当作普通按钮点击。

按右上角的播放按钮 ▶ 会进入 Play 画面并运行程序。
Layout 则会切换到 Layout 画面。

4-1. 菜单项目

NEW NODE 打开 CREATE NODE 画面来新建节点。长按背景也可以打开。
SAVE 为当前程序命名并保存（参见 4-2）。
LOAD 读取已保存的程序（参见 4-3）。
UNDO 撤销上一步操作。
REDO 重做被撤销的操作。
FIT 调整显示倍率和位置，使所有节点都能显示在画面内。
NEW 全部清除并新建。
SETTING 打开整个应用的设置（参见 4-4）。与 SETTING 节点是不同的东西。
OPEN HELP 打开本帮助页面。

在 Compo 内部进行编辑时，左侧的项目会变成 Compo 专用的项目。这部分将在“Compo 节点”一章中说明。

4-2. SAVE（保存）

命名后保存到本机。若已有同名文件则会覆盖保存。名称可使用半角英文字母、数字和部分符号。
AUTO后将启用自动保存，之后每 30 秒自动保存一次（Play 运行期间不会保存）。
EXPORT可以把程序导出为文件，便于备份或交给他人。
导出格式可以从 .ngz（gzip 压缩） 和 .json（文本） 两种中选择。
.ngz 只需把扩展名改为 .gz，就能用常见的解压软件取出其中的内容（JSON）。

最多可以保存 256 个。保存位置在所使用的浏览器内部，因此在其他设备或其他浏览器上看不到。
保存的数据存放在 nodegram 内部，因此如果删除手机上 nodegram 的快捷方式，数据也可能一并消失。
重要的数据建议用 EXPORT 保存成文件。

4-3. LOAD（读取）

会列出已保存的程序列表。通过名称旁边的按钮也可以删除。
IMPORT可以读取用 EXPORT 导出的文件。读取方式有两种：读取 会替换当前内容，追加读取 则保留当前程序并追加到其下方。

导入用 3D 软件制作的 .obj 文件后，3D 数据会作为 POLYGON 节点，或作为连接到 LINE 节点（3D 显示用）的 ARRAY 节点被读入。详情请参见 9-11. 3D 对象。

4-4. SETTING（应用设置）

整个应用的设置。这里更改的内容不会保存到程序中，只保留在本机上。
Wire：选择连线的形状（曲线／直线）。
NodeColor：选择节点的配色。
Language：切换显示语言。
日语、英语、中文（简体字）、法语、德语、印地语、印尼语、意大利语、韩语、葡萄牙语、俄语、西班牙语、泰语、土耳其语、越南语

每个场景的设置（FPS、Dynamics 等）不在这里，而是在 SETTING 节点 中进行。两者名称相同，请注意区分。

5. 在手机和电脑上的表现


在手机上
  • 触摸操作：
    单指平移，双指捏合缩放。长按、双击后拖动等操作与电脑上相同。

  • 横竖屏切换：
    旋转设备时画面会跟随横竖方向。Play 中的显示方向遵循 SETTING 节点所指定的方向（横=Horizontal／竖=Vertical），方向与预期不符时会显示提示。
  • iOS 的注意事项： 
    在 iPhone 等 iOS 设备上要全屏显示时，从 Safari 菜单点击下面的 ①、②，隐藏工具栏后就接近全屏，使用起来更方便。
    若要完全全屏显示，请从 Safari 菜单点按共享图标，选择“添加到主屏幕”。这样 nodegram 就能像应用一样使用，推荐这种方式。
    但删除添加到主屏幕的图标后，SAVE 的数据也可能消失。重要的数据请 Export 到手机内的文件夹中。

6. 全部节点说明



入／出为输入端子数／输出端子数。

常量

节点 输入数/输出数 说明
Constant 0/1 输出 Value 中设置的数字。

计算类

节点 入/出 说明
＋ 2/1 输出 输入① ＋ 输入② 的结果。
其实不用加法节点也可以：所有节点的输入端子都能连接多条连线并自动求和，所以在输入①上接两条线同样会输出相加的结果。
－ 2/1 输出 输入① － 输入② 的结果
× 2/1 输出 输入① × 输入② 的结果
÷ 2/1 输出 输入① ÷ 输入② 的结果。分母为 0 时输出 0。
√ 1/1 输出输入①的平方根。输入小于等于 0 时返回 0。
Compare 2/1 比较输入①和输入②（= > < ≠ ≧ ≦）。成立输出 1，不成立输出 0。
Not ( ! ) 1/1 输入①为 0 时输出 1，否则输出 0。
Pos Angle 2/1 由位置求角度。以度为单位输出 ArcTan2(输入②, 输入①)。
Angle Pos 1/2 由角度求位置。根据角度（度）输出 (cos, sin)。
Random 1/1 输出 0 以上、小于 Number 的随机整数。在 Play 开始时，以及输入①不为 0 的每一帧更新数值。打开 Use Seed 并指定 Seed 值后，每次开始 Play 都会重现相同顺序的随机数。
Int 1/1 取整。可在 Round 属性中选择 Floor / Round / Integer。
默认的 Floor 是取不大于输入值的最接近整数，2.8 变成 2，-0.1 变成 -1。Round 为四舍五入，Integer 为取整数部分。

数值操作类

节点 入/出 说明
Trigger 1/1 仅在输入从 0 变为非 0 的瞬间输出 1，持续 1 帧。
用 DELAY(F) 可以延迟指定帧数后再输出 1。
Counter 2/1 计数器。每帧加上输入①的数字，减去输入②，并输出内部保存的数字。
Type＝Clamp 时指定最大值和最小值，Loop 时在范围内循环。可设置 Value（初始值）和 Min/Max。
Var 2/1 可作为变量使用的节点。输出节点内保存的一个数值。
当输入②的置位信号为非 0 数值时，记住输入①。
可设置初始值。
Array 3/1 可作为数组使用的节点。
指定输入②的索引（数组中的位置，第 1 个为 0）即可输出数组中的值。索引从 0 开始，因此长度为 3 的数组索引是 0、1、2。指定小于 0 或大于等于 3 的值时视为无值，返回 0。
用输入③的置位信号，把输入①的值覆盖写入索引②所指定的数组元素。
初始值列表请用“,”（逗号）或换行分隔多个数字后填写。
数组可以与 Sound 节点配合当作乐谱使用，也可以与 Line 节点配合显示折线图形。还可以通过属性中的 SEQUENCER / LINE 按钮，在编辑器中以乐谱或折线图形的方式编辑（详见下文）。
此外，它也用于存放 3D 线框数据（参见 9-11. 3D 对象）。
GetPos 0/2 获取父对象当前的 X、Y 位置。可切换 WORLD/LOCAL。
GetRot 0/1 以逆时针为正，输出父对象当前的角度。可切换 WORLD/LOCAL。
Velocity 0/2 以每秒的数值输出父对象的 X/Y 速度（Y 以向上为正）。增大 Frames 会参考更多帧，变化更平缓。

Array 的专用编辑器（SEQUENCER / LINE）


  • LINE 编辑器：
    这是绘制连接到 Line 节点的折线的工具。
    编辑区域以中心为原点，X 向右为＋、Y 向上为＋，范围为 -99〜99。
    用 DRAW 绘制折线。绘制过程中 DRAW 按钮会变为 Endpoint 按钮，按下即可确定这一笔。
    用 MOVE 移动顶点，用 ERASE 删除单条线段，用 VIEW 移动视点，用 ◁ ▷ 撤销 / 重做。关闭后会转换为 x,y 的数列，x,y =（9999,9999）表示线在此处断开。
    把 LINE 节点指定为 Array 节点的父节点后，LINE 节点就会按 Array 的信息进行绘制。一个 Array 节点也可以指定多个父节点（LINE 节点）。


  • SEQUENCER 编辑器：
    这是制作连接到 Sound 节点的乐谱 Array 的工具。仅限八分音符、1 小节＝8 个、最多 500 小节、3 个八度。
    在 DRAW 模式下点击或拖动放置音符，在 ERASE 模式下拖动删除。
    关闭后会变成以 Do 为 0、Re 为 1 的八分音符数组，休止符为 99（超过 80 的数值全部视为休止符），最后一个音符所在小节的末尾之前会用休止符填满。半音按 0.5 处理。
    勾选 Chromatic 复选框后，12 音阶（Do=0、Do♯=1、Re=2、Re♯=3、Mi=4、Fa=5、Fa♯=6、Sol=7、Sol♯=8、La=9、La♯=10、Si=11）各占一格，数字上一个八度也变为 12。Sound 节点上也有相同的复选框，请保持设置一致。


  • 仅有 Array 是不会发出声音的，还需要类似下面链接中的程序。

    ▶ 打开示例

输出类

节点 入/出 说明
Text 2/0 显示文本。输入未连接时显示 Text 属性中指定的文字，连接后显示数值。用输入②控制显示的开关。数值会对小数点后第 6 位四舍五入，显示到第 5 位。可设置文字颜色、布局以及周围方框的显示开关。
Rect 3/0 矩形对象。Dynamics Off 时输入①/②为 x、y 坐标；Dynamics On 时为外力 x、y。输入③控制显示的开／关。可设置颜色、边框、Tag、大小、旋转、Sorting Layer 等。Broken by 1～3 用于指定能够破坏该对象的对方的 My Tag。
关于 Dynamics 和 Tag，请参考 9. 规格与细节。
Circle 3/0 圆形对象。除形状和 Radius 之外，输入和属性都与 RECT 相同。
Character 3/0 可以移动和跳跃的角色。输入①/②为移动速度，输入③在从 0 以下变为正值的瞬间跳跃。
跳跃力与输入值成正比，且仅在接地时有效。要使用物理和跳跃，需要同时打开 SETTING 和 Character 的 Dynamics。制作俯视视角游戏时，可以保持 Dynamics 打开而把 Gravity 设为 0。Flip 会根据朝向左右翻转纹理，AutoRot 会让朝向自动跟随前进方向，KeepOnScr 会把移动范围限制在屏幕内。
虽然有子端子，但不能作为对象的子节点。能指定为父节点的只有 WARP IN。
Shot 1/1 用输入①发射子弹。Bullet Count 为可同时存在的子弹数。My Tag 与对方的 Broken by 一致时会破坏对方；SHOT 一侧的 Broken by 1～3 用于指定会让子弹消失的对方种类或 Tag。只有成功发射的那一帧输出为 1。开启 Keep Off-Screen 后画面外的子弹会保留，超过子弹上限时旧的子弹会消失。
Line 5/0 绘制从 (X1,Y1) 到 (X2,Y2) 的线。连接了输入⑤(SET) 时，输入为非 0 值时更新外观，为 0 期间保持之前的形状。未连接时每帧更新。
把 ARRAY 指定为子节点后会忽略输入①～④，把数组按 x1,y1,x2,y2,,, 当作一笔画的折线绘制。x=9999, y=9999 表示线的断点。Coord 可选择 WORLD/LOCAL。
当子 ARRAY 为 3D 数据（x,y,z 三元组）时，会自动作为3D LINE绘制。详情请参见 9-11. 3D 对象。
Sound 3/0 输入①为音阶（Do=0、Re=1、…），输入②为音量，输入③为播放信号。输入①/②未连接时使用 Tone/Volume 属性。持续音在信号非 0 期间持续发声，衰减音和音效则在信号上升沿或音高改变时发声一次。音阶超过 80 的数值（如 99）为休止符。Tone 属性以 0.5 为步进（半音），但输入①可以使用连续的小数值。
打开 Chromatic 后，Tone 变为以半音为步进的 12 音阶数值（0=Do、1=Do#、2=Re…）。关闭时为 7 音阶，0.5 表示黑键。把 Array 作为音阶连接时，请与该 Array 的 SEQUENCER 一侧的 Chromatic 设置保持一致，否则音高会错位。
Polygon 7/0 用于显示 3D 模型面（多边形）的对象。无法从 CREATE NEW NODE 创建，只能通过 IMPORT .obj 文件生成。
输入包含 3D 位置坐标、3D 旋转和缩放。
详情请参见 9-11. 3D 对象。

操作类

节点 入/出 说明
Stick 1/2 虚拟摇杆。摇杆的 X 方向倾斜=输出①，Y 方向=输出②。支持模拟/数字切换，以及键盘/手柄的按键分配。
Button 1/1 虚拟按钮。按下期间输出 1。支持键盘/手柄的按键分配。
Keyboard 0/1 指定的按键被按下时输出 1。
Touch 0/3 屏幕触摸。触摸位置 X=输出①、Y=输出②（中心为 0,0），触摸期间输出③=1。

其他节点

节点 入/出 说明
TEXTURE 1/0 编辑并保存像素图，把图案贴到指定为父节点的对象上。可分配给 Rect、Circle、Chara、Shot、BG。可以指定多个父节点（对象节点）。
输入 0 时隐藏。把多个纹理连到同一个对象上，只让其中一个 Visible，就可以切换显示的纹理。
贴到对象上时可以选择是拉伸适配还是平铺。
不指定父节点时，也可以把纹理作为平面单独显示。
当背景图等需要大量使用同一张图时，也可以把一个纹理分配给多个对象。
纹理编辑器的详细用法请参见“TEXTURE 编辑器”。
SENSOR 0/1 输出与传感器区域（在 Layout 画面中设定的范围）重叠的对象数量。只要符合 Target 的条件或 Tag 1〜3 中的任意一个即视为对象，同一个对象即使符合多个条件也只计为 1 个。Target=SCREEN 时，返回传感器区域是否与当前显示范围重叠（0/1）。指定父节点后传感器会跟随父节点，且该父节点自身会被排除在判定之外。
ONBREAK 1/1 输出当前帧中被破坏的父对象或指定 Tag 的对象数量。父对象可以指定多个。
如果 Onbreak 节点不指定参照对象，也可以当作特效节点使用。当输入①从 0 变为非 0 值时，也会在节点位置产生特效。特效可以设置种类 (NONE, PARTICLE, LINE, CIRCLE, BOX) 和颜色。
ROTATE 1/0 用于旋转父子对象的旋转铰链。以 ROTATE 为父节点的对象会继承它的位置和旋转。输入①是相对于在 Layout 中设定的初始角度的旋转偏移量，正值表示逆时针角度。
SCREEN 3/2 控制 Play 时的摄像机。X/Y 为摄像机位置（有父节点时是相对父节点位置的偏移，Y 以向上为正），S 为缩放，最小 0.05。以 SCREEN 为父节点的对象会成为不受摄像机影响的固定 HUD。
把玩家对象指定为 SCREEN 的父节点后，视图就会跟随玩家移动。
RESTART 1/1 当输入从 0 变为非 0 时，把整个程序恢复到 Play 开始时的状态。运行中的位置、变量、计数器、数组、子弹等都会被初始化。触发重启的那个输入值在重启后仍会保留在输出上，因此可用于继承剩余生命数或分数。
COMPO 3/3 把多个节点合为一个的部件。E＝启用/禁用，1 和 2＝与内部交换数值。
Compo 节点的详情请参见 7. Compo 节点。
  • TEXTURE 编辑器：
    从 TEXTURE 节点属性中的“Edit Texture”按钮打开。可以绘制像素图，并贴到指定为父节点的对象上。
    Draw用所选颜色画点。拖动可以连续绘制。
    Paint把相连的同色区域一次性填充。
    Pick吸取图中的颜色作为当前颜色。
    View进行视图的放大和移动。
    Copy / Paste选择范围复制，并粘贴到其他位置。
    ◁ / ▷UNDO / REDO

    颜色从下方的调色板中选择。想要擦除时，请选择透明色后绘制。
    点数可在属性的 Size 中更改。图像尺寸最大可到 256*256，但 UNDO 次数会减少，编辑器也会变慢。SHOT 对象请尽量使用较小的纹理。
    编辑结束后，用右上角的 × 关闭。
    长按调色板可以从全色中选择颜色。

    在电脑上，可以把在其他软件中复制的图像粘贴到编辑器的画布中。在手机上，根据软件和机型的不同也可能可以。

传送类

节点 入/出 说明
WARP IN 1/0 把对象瞬间移动到别处的机制的“入口”。作用于指定为子节点的对象。输入非 0 时，指定为子节点的对象会移动到具有相同 Index 的 WARP OUT 的位置和角度。在持续输入非 0 期间会固定在那里，变为 0 后解除固定，重新可以自由移动。属性只有 Index。不能放入 Compo 中。
WARP OUT 0/0 传送的“出口”。由具有相同 Index 的 WARP IN 送来的对象会移动到这个位置和角度。属性只有 Index。在 Layout 画面中可以移动位置和旋转（因为没有大小，所以无法调整尺寸）。也可以指定父对象让它一起移动。不能放入 Compo 中。

连接类

节点 入/出 说明
IN 1/0 在把节点的输出连到很远的地方时使用。连接到 IN 节点的信号会输出到具有相同索引的 OUT 节点。不能创建多个具有相同索引的 IN 节点。指定 Compo 节点的索引后，也可用于访问 Compo 内部。
关于 Compo 节点请参见 7. Compo 节点。
OUT 0/1 在从很远的地方连到节点的输入时使用。连接到 IN 节点的信号会输出到具有相同索引的 OUT 节点。可以创建多个具有相同索引的 OUT 节点。进入 IN 的数值会输出到所有具有相同索引的 OUT 节点。指定 Compo 节点的索引后，也可用于访问 Compo 内部。
关于 Compo 节点请参见 7. Compo 节点。

设置类

节点 入/出 说明
MEMO 0/0 写在画面上的注释（备忘）。Play 时不会显示。
BG 0/0 运行画面的背景。每个场景一个，始终位于最底层。
分配 TEXTURE 节点后，会把该图案平铺满整个背景。未分配 TEXTURE 时，用 Color 的单色填充。
SETTING 0/0 设置整个场景。
可以更改手机的横竖屏设置（ScreenOrient）、Play 画面尺寸指定（ScreenSize、ScreenLong、ScreenShort）、FPS、Dynamics（Gravity、Friction%、Bounce%、Drag%）、Play 停止按钮颜色（StopBtnCol）以及 GridSnap 设置。每个场景只能创建一个。
当场景中存在 3D 相关节点时，还会显示用于指定视点高度和到屏幕距离的属性。

7. Compo 节点

  • 可以把多个节点当作一个节点来使用的特殊节点。

    比如说，如果同样处理的节点组合在程序中出现了 10 次，总会想以某种方式集中到一处来复用吧。
    在 nodegram 中，可以把多个节点合并成一个 Compo 节点，然后复制这个 Compo 节点来使用。

    想做 10 个相同的敌人时，可以先做好 1 个的程序，把这 1 个所用的节点们合并成一个 Compo，再复制 Compo 并摆放到 Layout 中。

    复制出来的 Compo 节点在程序上是同一个东西，所以改动其中一个程序，其他 Compo 的程序也会随之改变；但各自持有的坐标、变量、生存时间等会按 Compo 分别处理。

  • Compo 节点的创建步骤
  1. 先一起选中想要合并的节点们。
    批量选中使用双击＋拖动来完成。
    双击的第二次点击不要松开鼠标，直接拖动进行框选。
    在手机上大概是“咚、咚、—”的感觉。
    （这个示例程序中，左边是自机，方框圈住的区域是一架靠近自机的敌机的程序）



  2. 在选中多个节点的状态下长按其中任意一个节点，就会出现菜单。选择“MAKE COMPO”后会询问是否合并为 Compo，按“Yes”即可。




  3. 多个节点变成了一个名为“C1”的 Compo 节点。


  4. 长按（或双击）C1 节点，就会进入编辑 Compo 内部的 NodeEditor。
    原先连到 Compo 的连接线，变成了名为“C1 1”“C1 2”的 OUT 节点。

    按右侧的“MENU”按钮，可以看到左列已变成 Compo 相关的命令。
    按“Duplicate”会复制这个 Compo 节点。
    按右下角的“PARENT”按钮，会离开这个 NodeEditor，返回上一层的 NodeEditor。



  5. 在上层的 NodeEditor 中可以确认已经生成了多个 Compo 节点。
    因为也想给“C1 (2)”传入相同的输入值，所以把它的输入输出也连接起来。



  6. 按“LAYOUT”按钮，逐个调整各 Compo 的布局。


  7. 按 Play 按钮“▶”，可以看到有多架敌机，并且各自独立运动。

  8. 想大量复制 Compo 时，请一起选中 Compo 节点，长按后执行“Duplicate”。
    另外，要给所有 Compo 节点传入相同数值时，使用 IN 节点和 OUT 节点会很方便。


  • Compo 节点与实例

    当两个 Compo 节点内容相同，且编辑其中一个的内容会导致另一个也随之改变时，我们称“这两个节点是实例关系”；用复制来创建时，称为“创建 Compo 节点的实例”。
    Compo 编号相同的节点互为实例关系，共用同一个程序。
    （顺带一提，切断实例关系称为 Unique，位于 Compo 的滑动菜单中。详见下文）

    C 后面的编号相同，就是互为实例关系的同一个 Compo。
    “C1 (1)”和“C1 (2)”是实例关系。
    “C1 (1)”和“C2 (1)”是不同的 Compo，不是实例关系。
    ( ) 内的数字是用于区分同一个 Compo 的编号。

    即使 Compo 之间是实例关系，Play 时各个 Compo 的参数也是分别处理的。
    角色的产生、消失、坐标，以及节点内的 count、var、array 等都持有各自独立的值。

  • Compo 节点内的 MENU


    Duplicate、Delete：复制和删除 Compo 节点。

    Unique    ：切断 Compo 节点实例关系的功能。想沿用 Compo 的内容制作另一种敌人时使用。Compo 编号会变成别的编号。

    Expand    ：把正在操作的 Compo 中的节点们放回主 NodeEditor，正在操作的 Compo 随之消失。这是 Make Compo 的逆操作。与之互为实例关系的 Compo 不会一起被 Expand（展开）。

  • Compo 节点与 IN、OUT 节点

    Compo 节点只有两个输入和两个输出端子，但通过 IN 节点、OUT 节点可以增加输入。
    IN、OUT 节点的属性中可以指定 Compo 编号，因此可以把数值传给特定的 Compo。


    在 Compo 内可以使用不带 Compo 编号的 IN 节点。
    在 Compo 内不能使用不带 Compo 编号的 OUT 节点（因为相同的 OUT 节点不能创建多个）。

    请注意：带 Compo 编号的 IN、OUT 节点，即使设置完全相同，位于 Compo 内部还是外部，其含义也完全不同。
    上图中的“IN 节点（蓝色）：C1 索引 2”在 Compo 内和 Compo 外都有，但含义不同。Compo 内的那个连接到 Compo 的输出 2；而 Compo 外的那个连接到 Compo 的输入 2，负责把数值传给 Compo 内的“OUT 节点：C1 索引 2”。

  • Compo 的 Enable 输入与 Enable 输出

    把 Compo 节点当作角色使用时，可以用 Enable 输入输出来控制该角色的出现和消失。

    Enable 输出在角色存在期间输出 1，角色因破坏等原因消失后输出 0。

    当 Enable 输入从 0 变为 1（非 0）时，Compo 内的程序启动，角色变为有效。要让角色持续存在，必须持续输入非 0 值。输入变为 0 或角色被破坏时，角色就会消失。
    Enable 输入什么都不连接时，等同于一直输入 1。

    即使是已消失的角色，只要把输入从 0 变为非 0，角色就能从初始状态重新开始。
    下面是角色被破坏后 3 秒重新在初始位置生成的程序。


  • Compo 节点内的父只有一个

    Compo 内对象的父子关系中，不能存在多个父对象节点。目前不支持在一个 Compo 节点中创建两个角色的情况。
    即使有两个父，只要为这两个设置了共同的父就没有问题。
    一个对象节点都不持有（没有任何父）的状态也没有问题。


  • Compo 内无法创建的节点

    BG、Setting、Stick、Button、Screen、OnBreak 无法在 Compo 内创建。

9. 规格与细节

9-1. 仅限 2D

nodegram 仅限 2D。坐标为 X（右为＋）、Y（上为＋）两个轴。在 Setting 节点中打开 Dynamics 后，角色会朝画面下方掉落。
制作俯视视角游戏时，请在 SETTING 节点中关闭 Dynamics，或者把整个游戏的重力设为 0。

9-2. FPS

目标帧率可在 SETTING 节点中选择 60 或 30（默认 60）。节点的求值和物理都以该 FPS 为基准推进。处理变重时 Play 的表现会变慢，帧率会低于指定值。

9-3. Dynamics（物理行为）

Rect、Circle、Character、Shot 等对象可以设置物理模式（Dynamics）。其行为与 Unity 的 Rigidbody2D 基本相同。

模式 行为
Off 无物理。仅通过节点输入（X,Y）直接移动坐标。
Static 不动的墙壁和地板。不会因重力或碰撞而移动。
Dynamic 受重力和碰撞影响并按物理运动。节点的 X/Y 输入会作为“力”施加。
Kinematic 不会因重力和碰撞移动，但可以通过节点输入强制移动，并能与其他 Dynamic 发生碰撞和干涉。

没有比重设定，大致以普通木材为基准。

9-4. SortingLayer（显示顺序）

由各对象的 SortingLayer（0〜100，默认 50）决定 Play 画面中的显示叠放顺序。数值越大越靠前（上）。BG（背景）始终位于最底层。
数值相同的对象按添加顺序显示。

9-5. 坐标

  • 坐标系为 X（右＋）、Y（上＋）。Layout 的中心是原点 (0,0)。
  • 角度以度（degree）表示，逆时针为＋。0°＝右（X＋），90°＝上（Y＋），180°＝左（X−），270°＝下（Y−）。ANGLE POS / POS ANGLE / GetRot / ROTATE / 对象的 Angle 属性全部统一为这个方向。
  • 通过对象 Property 中的 Coord 属性，节点输入的 X/Y 数值的含义会发生变化。
    • WORLD：把输入值作为绝对坐标应用（有父对象时为以父为基准的局部绝对坐标）。
    • LOCAL：把输入值作为相对于初始摆放位置的相对偏移应用。指定了父对象时，也包含相对父的偏移（Parent 坐标系）。
  • 关于 3D 对象的坐标，请参见 9-11. 3D 对象。

9-6. 分辨率

Play 时的显示区域是 Layout 中灰色矩形的大小。
画面方向（横=Horizontal／竖=Vertical）可在 SETTING 节点（不是 Setting 菜单）中切换，并会按实机的屏幕尺寸适配显示。
若要使用固定分辨率，请从 Setting 节点的 ScreenSize 进行设置。

9-7. Tag

Tag 就是分组。
例如可以给所有小兵敌人加上“Enemy_tiny”这个 Tag，或者用“bg_destroyed”“bg”来区分可破坏的背景和不可破坏的背景。
Shot、OnBreak、Rect、Circle、Character 等节点都会使用 Tag。


9-8. 节点的操作


  • 一个节点的输入可以连接多条线。有多个输入时，会把这些数值之和传给节点。图中最上面的端子接收的是 10+20→30。

  • 节点之间的父子连接（从上方端子连到下方端子），除了控制对象的移动（Transform）之外，也用于指定“关系”。
    例如 Texture 节点与对象类节点、OnBreak 节点与被检测的对象节点、Array 节点与 Line 节点。
    通常一个父可以有多个子，但一个子不能指定多个父。
    Texture 节点、OnBreak 节点、Array 节点可以持有多个父（分配目标）。


9-9. 一帧内的处理

所有节点都是同时处理的。
不会因为先创建了哪个节点而改变结果。

对象节点等每帧处理一次。
Counter、Var、Trigger、Random、Array 等“记住数值的节点”也是每帧只更新一次。
＋ 和 × 这类计算节点不记忆数值，因此在需要时才计算。
不过，当计算节点构成回路时，一个节点在一帧内也只会被处理一次。

9-10. UNDO / REDO

MENU 的 UNDO / REDO 可以撤销和重做节点的创建、删除、移动、连接、属性更改等操作。最多可回退 50 步。

TEXTURE / LINE / SEQUENCER 各编辑器都拥有各自独立的 UNDO 历史。请使用编辑器内的 ◁ / ▷ 按钮操作。LINE Editor、SEQUENCER 也可回退 50 步，TEXTURE 的可撤销次数则随尺寸而变化。

另外，Play 的运行不在撤销范围内，保存和读取也无法撤销。

9-11. 3D 对象


nodegram 中有 Polygon 和 ARRAY + LINE（3D 显示用） 这两种用于显示 3D 对象的节点。两者都只能通过 IMPORT .obj 文件来创建（无法从 CREATE NEW NODE 创建）。

不过 nodegram 本身终究是2D 平台。3D 对象只是把它的外观当作 2D 素材来使用，和其他 2D 对象一样，显示顺序由 Sorting Layer 的设置决定。位于同一 Sorting Layer 的多个 Polygon 节点会作为一个 3D 显示统一处理，前后的深度关系也会正确地叠放绘制。

3D 对象具有 Z 坐标。屏幕所在位置为 z=0，向里为 +z，视点方向为 -z。从视点到屏幕的距离以及视点的高度可在 setting 节点中更改。
也可以与 2D 对象建立父子关系，但此时建议在 z=0 下使用。

要作为 LINE（3D 显示用）绘制，需要把作为 LINE 节点子节点的 ARRAY 的值设为 x,y,z 三元组排列的数列。在遇到分隔符 (9999,9999,9999) 之前的部分会连成一条线，之后的部分作为新的线处理（格式：x,y,z, x,y,z, ,,, 9999,9999,9999, x,y,z, ,,,, 9999,9999,9999）。ARRAY 的父也可以指定多个 LINE。

10. 注意事项

  • 使用手机时：
    把 nodegram 的快捷方式添加到主屏幕后，就能像应用一样使用。但和应用一样，删除它（删除主屏幕的快捷方式）后 Save 的数据很可能会消失。完成的程序请使用 Export 备份为外部文件。

    在某些手机浏览器上，显示或操作位置可能会错位。
    这种情况下，请退出 nodegram，清除任务（不是删除应用），把手机方向摆正为横向后重新启动，即可恢复正常。
  • 自动保存：
    当 save 画面中的“auto save”处于打开状态时，每 1 分钟会覆盖保存到上一个文件。想以别的名称保留时，请用 Save 取一个新名字。
